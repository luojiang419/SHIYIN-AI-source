# 100 - 影视制作节点端口与模特复用差异备份

版本：1.0.246
日期：2026-08-22

## 变更范围

- `static/js/canvas-film-nodes.js`
- `static/js/canvas.js`
- `static/js/smart-canvas.js`

## 代码前后对比

### 1. 生成视频输入端口排序

修改前，`film-video` 端口按“全部演员 → 全部服装 → 全部道具”生成：

```js
演员A、演员B、服装A、服装B、道具A、道具B
```

修改后，每个演员的资产端口在同一组内生成：

```js
分镜图、演员A、服装A、道具A、演员B、服装B、道具B
```

实现方式是将 `inputPorts()` 的演员循环改为每轮返回 `actor / outfit / prop` 三个端口，并使用 `Array.prototype.flat()` 展开。

### 2. 自动复用影视分镜上游模特

修改前，`classicFilmAssets()` 与 `filmSmartAssets()` 只读取当前视频节点的直接连接，未读取影视分镜节点的演员连接。

修改后：

- 普通画布沿 `film-video.storyboard` 输入向上追溯 `film-storyboard → output → film-video` 链路。
- 智能画布沿 `film-video.storyboard` 输入追溯直接上游 `film-storyboard` 节点。
- 仅读取上游影视分镜节点的 `actor-*` 端口，不跨普通生成节点复用。
- 当前视频节点某个演员端口没有直接资产时，注入对应的上游模特资产，并标记 `autoReuse`。
- 根据继承到的最大演员序号写入 `autoActorCount`；共享节点模块的 `effectiveActorCount()` 使用显式演员数量与自动数量的较大值，因而自动出现演员B等新端口。
- 输入槽继续复用已有的“绿点 + 已连接”状态渲染，因此继承资产会亮起绿灯并显示已连接。
