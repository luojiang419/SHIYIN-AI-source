# 100：画布下载逐文件保存差异备份

## 修改范围

- `static/js/canvas.js`
- `tests/test_canvas_download_and_asset_sync.py`

## 代码差异摘要

### 修改前

`downloadOutputNodeImages()` 将输出 URL 发送到 `/api/canvas-assets/download`，服务端返回 ZIP Blob，再通过 `<a download="...zip">` 下载。

### 修改后

- 新增输出项规范化，保留媒体原始名称并过滤不可下载 URL。
- 新增安全重名处理，按 `name (2).ext`、`name (3).ext` 递增。
- 新增目录选择与文件写入流程：`showDirectoryPicker` → `fetch` → `getFileHandle` → `createWritable`。
- 对取消选择使用 `AbortError` 无害返回；写入异常调用 `abort()`，避免留下未完成写入。
- 右键下载入口不再构造 ZIP 文件名，也不再调用 ZIP 接口。
