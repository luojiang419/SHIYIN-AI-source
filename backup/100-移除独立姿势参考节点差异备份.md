# 源码备份 100：移除独立姿势参考节点

## 备份范围

本次备份对应独立姿势参考节点清理模块，基于工作区修改后的源码记录关键差异。原始代码仍可通过 Git 历史恢复；本文件用于快速追溯本次模块的改动意图和影响范围。

## 文件差异

### 删除文件

- `static/js/pose-reference-editor.js`：删除独立 3D 姿势编辑器及导出逻辑。
- `static/css/pose-reference-editor.css`：删除独立姿势编辑器及节点样式。

### 页面与快捷入口

- `static/canvas.html`：删除姿势编辑器 CSS/JS、普通画布工具栏“导演台”和创建菜单“导演台”。
- `static/smart-canvas.html`：删除姿势编辑器 CSS/JS和智能画布创建卡片。
- `static/js/shortcut-actions.js`：删除 `create.poseReference` 动作注册。

### 普通无限画布 `static/js/canvas.js`

- 删除 `addPoseReferenceNode` 构造函数。
- 删除菜单创建分支、特殊节点渲染分支、特殊节点绑定分支和默认尺寸分支。
- 从可创建、可输出、可连接、媒体引用和生成器来源类型列表中删除 `poseReference`。
- 保留 `poseReferenceSourceId` 与 `pose-reference` 输入角色，因为它们属于一键复刻/动作参考输出链路。

### 智能无限画布 `static/js/smart-canvas.js`

- 删除 `createPoseReferenceNode` 构造函数。
- 删除智能菜单映射、特殊主体、标题、绑定和拖放提示中的独立节点分支。
- 保留一键复刻节点的 `pose-reference` 输入角色和骨架输出关联字段。

### 特殊节点适配器 `static/js/canvas-special-nodes.js`

- 删除独立姿势节点标题、主体渲染和事件绑定函数。
- 从 `window.CanvasSpecialNodes` 导出对象中删除对应接口。
- 保留 `poseReplicateBodyHtml`、动作参考输入和骨架提取功能。

### 测试

- 原姿势编辑器存在性测试改为验证资源、入口和绑定已移除。
- 快捷动作、特殊节点和增量渲染测试同步调整为新的节点集合。
