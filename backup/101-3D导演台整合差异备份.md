# 101-3D导演台整合差异备份

## 修改范围

- 整合上游 `tigerowo/infinite-canvas` 的静态 3D 导演台应用、模型和资源。
- 新增普通/智能画布 `director3d` 节点，支持内嵌导演台、项目状态回传、截图上传和输出节点创建。
- 原 `poseReference` 节点显示名称改为“导演台”。
- 原 `blenderDirector` 节点显示名称改为“外部导演台”。
- 版本递增到 1.0.334。

## 关键前后对比

- `姿势参考` → `导演台`
- `3D 导演台`（Blender 外部桥接）→ `外部导演台`
- 新增 `director3d` 节点及 `/static/director/` 静态资源。
- 新增截图上传和输出节点创建流程。

## 详细代码位置

- `static/js/director-3d.js`、`static/css/director-3d.css`
