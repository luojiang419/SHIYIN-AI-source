## 代码前后对比

### 普通画布 `arrangeIdsByConnections`

修改前：将选中节点按媒体、提示词/循环、功能、输出等类别分桶，再用网格列布局。输出节点即使连接到下一个功能节点，也会被统一放到输出类别列中。

修改后：

```js
const outgoing = new Map(selectedNodes.map(node => [node.id, new Set()]));
const incoming = new Map(selectedNodes.map(node => [node.id, new Set()]));
// connections 投影到组节点后构建有向图
// Kahn 拓扑排序计算 levels
// levels 相同的节点放在同一列，上下排列
```

共享输入节点只存在一个图节点，多个下游节点共享同一个 `outgoing` 分支；输出节点连接下一个功能节点时，后者自然进入更右侧层级。

### 智能画布 `arrangeSmartIdsByConnections`

采用与普通画布一致的拓扑层级算法，连接来源使用 `canvas.connections`，智能分组成员先投影到分组节点，再进行层级计算。

### 循环连接兜底

当连接图存在循环、无法找到拓扑起点时，未处理节点会稳定地放到已解析层级之后，避免整理操作失败或节点消失。
