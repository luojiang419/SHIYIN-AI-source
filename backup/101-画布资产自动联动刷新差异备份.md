# 101：画布资产自动联动刷新差异备份

## 修改范围

- `static/js/asset-manager.js`
- `tests/test_canvas_download_and_asset_sync.py`

## 代码差异摘要

### 修改前

- `canvasAssetsLoaded` 只在手动点击“刷新资源”时更新。
- 画布资产标签按钮位于 `#assetManagerRoot` 外部，原有 root 委托点击无法触发 `ensureTabData`。
- 素材库没有处理画布实时变更消息。

### 修改后

- 标签按钮直接调用 `ensureTabData(activeTab)`，首次进入自动读取。
- 使用 `canvasAssetsChangeToken`/`canvasAssetsLoadedToken` 判断是否需要更新。
- 使用定时器合并短时间内的连续 `canvas_updated` / `entity.changed` 消息，并复用进行中的请求。
- 页面隐藏时只记录变更，恢复可见或重新进入标签后补做刷新。
