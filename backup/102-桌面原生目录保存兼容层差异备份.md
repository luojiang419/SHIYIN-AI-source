# 1.0.303 画布批量下载桌面兼容层备份

## 改动前

- 画布 iframe 只调用 `window.showDirectoryPicker()`。
- Windows WebView2 iframe 中该 API 为 `undefined`，点击“下载全部”会停留在 Saving 状态，无法选择目录。
- Tauri 桌面壳没有提供选择目录后逐文件写入的 IPC 命令。

## 改动后

- `static/js/canvas.js` 在 File System Access API 不可用时，通过父页面消息请求桌面保存服务。
- `static/js/desktop-updater.js` 增加目录选择、逐文件 fetch 和 IPC 写入流程；目录只选择一次，不创建 ZIP。
- `src-tauri/src/lib.rs` 增加 `choose_download_directory`、`write_download_file` 两个命令，并拒绝文件名路径穿越。
- 增加 Rust 单元测试，验证安全文件名写入和路径穿越拦截。

## 验证

- Rust 单元测试：9 passed。
- 画布下载/资产联动专项测试：4 passed。
- JavaScript 语法检查通过。
