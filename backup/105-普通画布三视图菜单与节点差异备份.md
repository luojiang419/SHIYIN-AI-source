- `static/js/canvas.js`
- `static/canvas.html`
- `static/css/canvas-special-nodes.css`
- `tests/test_canvas_multi_view.py`
- 版本源与更新说明文件

## 代码差异摘要

### 普通画布快捷入口

修改前，`renderSelectionHub()` 只有全景、多角度、灯光和动作提取等动作，没有创建三视图。

修改后加入：

```js
{id:'multi-view', label:langIsEn() ? 'Create three views' : '创建三视图', icon:'panels-top-left'}
```

### 节点与端口

新增 `multiView` 节点和 `CLASSIC_MULTI_VIEW_INPUT_SLOTS`：

```text
model-front / model-side / model-back
product-front / product-side / product-back
front-detail / back-detail / accessory
```

细节、背面细节和配饰允许多个来源；模特侧面或背面未连接时使用模特正面作为生成主体。

### 生成输出

新增 `runClassicMultiViewNode()`，先校验模特正面与产品三角度，再用 `Promise.all` 提交：

```js
taskFor('front', true) // 16:9 三视图模卡
taskFor('front')       // 正面 9:16
taskFor('side')        // 侧面 9:16
taskFor('back')        // 背面 9:16
```

结果统一写回节点与下游输出节点，保持普通画布媒体连线协议兼容。

### 版本统一

根目录 `VERSION`、`package.json`、Tauri 配置、Cargo、后端 `APP_VERSION`、更新元数据和安装阶段全部统一为 `1.0.210`。
