# 170 - 影视制作节点双画布差异备份

版本：1.0.236
模块：影视制作专业节点基础接入

## 变更范围

- 新增 `static/js/canvas-film-nodes.js`：影视节点领域模型、演员编号、动态端口、资产映射、模型规则、`@` 引用菜单和视觉解析。
- 新增 `static/css/canvas-film-nodes.css`：普通/智能画布影视节点与角色端口样式。
- 修改 `static/js/canvas.js`：接入普通无限画布的影视二级菜单、节点创建、动态角色端口、输入映射、图片/视频生成和输出链路。
- 修改 `static/js/smart-canvas.js`：接入智能无限画布的 `film-storyboard` / `film-video` 特殊节点、输入连接、生成和视觉解析。
- 修改 `static/canvas.html`、`static/smart-canvas.html`：加载共享资源并暴露影视制作入口。
- 修改 `static/css/smart-canvas.css`：智能画布影视二级功能卡片样式。
- 新增 `tests/test_canvas_film_nodes.py`：影视节点契约测试。

## 关键前后对比

### 节点类型

```diff
- 仅有电商节点、普通图片/视频生成节点
+ film-storyboard：分镜合成
+ film-video：生成视频
```

### 动态演员端口

```diff
- 固定端口，无法区分多个演员及其关联资产
+ actorCount 默认 1，点击“添加演员”递增到最多 8 人
+ 分镜合成：演员A/演员B/场景/线稿分镜
+ 生成视频：分镜图/演员A/演员B/服装A/服装B/道具A/道具B
```

### 资产映射与引用

```diff
- 生成提示词只包含用户手写文本
+ 根据连线端口顺序自动生成“图1是模特A”等映射
+ 即梦使用图N，可灵使用图片N，MiniMax H3 使用 <Picture N>
+ 文本框输入 @ 时弹出当前已连接资产，选择后将引用标记插入光标位置
```

### 视觉解析

```diff
- 用户需要手动描述线稿画面或人物动作
+ 分镜合成提供“解析画面”，调用 /api/canvas-llm 回填景别、构图、动作和光线
+ 生成视频提供“解析动作”，调用 /api/canvas-llm 回填动作、朝向、镜头运动和节奏
```

### 智能画布连接修复

```diff
- addConnection 在处理带 inputRole 的连线时引用未定义的 to 变量
+ 先解析 target 节点，再按 target.specialType 判断多输入角色端口
```
