# v1.0.237 影视节点主题布局修复差异备份

- `static/css/canvas-film-nodes.css`
- `static/css/smart-canvas.css`
- `tests/test_canvas_film_nodes.py`
- 版本文件由 `1.0.236` 递增至 `1.0.237`

## 具体前后对比

### 主题颜色

```text
之前：影视节点按钮、标签、映射芯片使用 #7c3aed、#8b5cf6、#64748b、#94a3b8 等固定紫色和蓝灰色。
之后：统一使用 --strong、--strong-text、--soft、--line、--text、--muted、--card-solid 等画布主题变量。
```

### 端口标签

```text
之前：经典画布端口标签通过 left:16px 放在节点内容区内，覆盖演员摘要、场景和线稿分镜文字。
之后：端口标签固定在节点左侧，以 right:100% 定位，不参与正文排版；智能画布也采用同样的外侧标签策略。
```

### 控件布局

```text
之前：按钮依赖内容宽度，视频节点四个设置控件容易挤压或溢出。
之后：解析/生成按钮采用等分网格；图片设置采用双列网格；视频设置采用带 minmax(0, ...) 的四列网格，文本和下拉框可收缩并显示省略号。
```

### 回归保护

新增测试确认影视 CSS 使用主题 token、端口标签位于内容外侧，并禁止影视样式重新引入紫色硬编码。
