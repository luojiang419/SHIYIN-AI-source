# v1.0.241 输出节点自动避让差异备份

## 修改范围

- `static/js/canvas.js`
- `static/js/smart-canvas.js`
- `tests/test_arrange_selected_layout.py`

## 问题

输出节点创建时使用固定的 `source.x + 偏移量`，没有考虑上游节点的真实宽度，也没有检查候选位置是否与画布中的其他节点相交。因此当节点尺寸较大、输出节点内容变化或右侧已有节点时，输出节点会重叠上游节点或相邻节点。

## 详细前后对比

### 经典画布

修改前，通用输出、图片编辑输出、姿态输出和姿态复刻输出分别使用固定坐标或旧的局部坐标计算；其中通用输出直接使用 `node.x + dx`。

修改后，在输出节点加入 `nodes` 后立即调用 `positionCanvasNodeRelative(output, source, 'downstream')`。该函数使用经典画布的 `canvasFreeNodePoint`：

1. 读取上游和新节点的实际矩形尺寸。
2. 从上游右边界外 72px 开始寻找候选位置。
3. 逐列、逐行检查候选矩形与全部已有节点的相交关系。
4. 只有找到不相交位置才返回坐标。

### 智能画布

新增 `smartOutputPointForImages`，统一计算包含实际图片布局尺寸的输出候选位置。`nextOutputPositionForSource`、姿态参考图、建筑多视图、循环输出槽、网格拆分和工作流输出都改为使用 `smartFreeNodePoint` 或该辅助函数。

修改前的典型代码：

```js
createNode((node.x || 0) + nodeRect(node).width + 40, node.y || 0, images);
```

修改后的典型代码：

```js
const point = smartOutputPointForImages(node, outputImages);
const created = createNode(point.x, point.y, outputImages);
```

### 测试

在 `tests/test_arrange_selected_layout.py` 增加自动输出节点定位契约断言，确保经典和智能画布继续调用统一的安全空位算法。
