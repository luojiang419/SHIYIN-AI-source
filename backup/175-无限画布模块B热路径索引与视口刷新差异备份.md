# 模块 B 无限画布热路径索引与视口刷新差异备份

## 修改范围

- `static/js/canvas.js`
- `static/js/smart-canvas.js`
- `tests/test_canvas_hotpath_indexes.py`
- `tests/test_canvas_interaction_performance.py`
- `开发文档/无限画布性能优化开发文档-v1.md`

## 目标

在不改变节点、连线、端口命中、媒体、输入法、远程同步和撤销重做语义的前提下，减少大场景下重复的 DOM 查询、端口布局读取和节点尺寸计算，并验证视口变换无需重新计算世界坐标连线。

## 详细前后对比

### 经典画布

修改前，经典画布虽然已有 `canvasNodeIndex`，但 `estimatedNodeRect()`、`portPoint()`、`renderLinks()`、节点增量 patch 和刀切命中仍会反复执行节点选择器查询；平移/缩放/缩放预览路径也会在 `applyViewport()` 后调用 `renderLinks()`。

修改后新增并维护：

```js
canvasNodeDomIndex
canvasPortDomIndex
canvasNodeRectIndex
canvasPortGeometryIndex
```

`rebuildCanvasDomIndexes()` 在全量渲染、增量 mutation、节点创建和节点刷新后重建；`invalidateCanvasGeometry(ids)` 仅清理移动或尺寸变化节点的矩形和端口几何。`renderLinks()` 优先复用模型/DOM索引，端口几何命中缓存失效时才读取 `getBoundingClientRect()`。`centerViewportOnWorldPoint()`、`fitAllNodesViewport()`、`exitZoomPreview()` 和 `exitZoomPreviewToNode()` 只更新 world transform 及相关 UI。

### 智能画布

修改前，智能画布的连接层、小地图和拖动过程重复执行 `nodeRect()` 和 `.image-node[data-id]` 选择器查询。

修改后新增并维护：

```js
smartNodeDomIndex
smartPortDomIndex
smartNodeRectIndex
smartPortGeometryIndex
```

`cachedSmartNodeRect()` 和 `cachedSmartPortPoint()` 为连接层提供稳定的世界坐标缓存；节点拖动和尺寸变化按节点失效，结构性 render 后重新建立 DOM/矩形索引。端口拖动视觉、节点位移和小地图矩形更新优先读取索引。

### 测试

新增 `tests/test_canvas_hotpath_indexes.py`，验证两套画布的索引集合、索引读取路径、局部失效和视口变换约束；更新 `tests/test_canvas_interaction_performance.py` 以匹配复用模型/DOM索引的新契约。
