## 经典画布差异

修改前：`scheduleLinksRender()` 的 rAF 回调始终执行 `renderLinks()`，节点拖动/尺寸变化时遍历全部连接并读取两端端口几何；临时连线也由全量函数统一处理。

修改后：

- 增加 `CLASSIC_INCREMENTAL_LINKS`、`classicConnectionDirtyIds` 和 `classicConnectionStructureDirty`。
- 增加 `markClassicConnectionsDirtyForNodes()`，节点移动/尺寸变化只标记相邻连接。
- 增加 `renderClassicConnectionPatch()`，按连接 ID 更新 path、hit path、删除按钮；连接结构变化、索引不可用或异常时回退 `renderLinks()`。
- 增加 `renderClassicTempLink()`，临时连接使用独立 DOM path。
- 滚轮缩放只应用 world transform，临时连接存在时才刷新其独立 path。

## 智能画布差异

修改前：普通节点拖动的交互 rAF 每帧调用 `refreshConnectionLayer()`，重新拼接完整 SVG、替换整个 connection layer 并重新绑定事件。

修改后：

- 增加 `SMART_INCREMENTAL_CONNECTIONS`、`smartConnectionDirtyIds`、`smartConnectionDom` 和结构回退标记。
- 普通单连接项输出 `data-connection-id`，全量渲染后建立 path/hit/dot/cut DOM 索引。
- 增加 `renderSmartConnectionIncremental()`，仅更新受影响普通连接的曲线、样式、端点圆点和刀切按钮位置。
- 分组、历史、合并连接、拓扑或索引不匹配时返回 false，由 `scheduleInteractionLayerRefresh()` 调用全量 `refreshConnectionLayer()`。
- `port-drag-temp` 保持独立 path，并在连接层替换时恢复当前几何。

## 测试差异

新增 `tests/test_canvas_incremental_connections.py`，静态验证：

1. 两套增量开关和脏连接集合存在。
2. 经典拖动/缩放只标记相邻连接，且保留全量回退。
3. 经典临时 path 不遍历连接集合。
4. 智能 connectionId DOM 索引、复杂拓扑回退和普通交互增量路径存在。
5. 智能临时端口 path 与普通连接层隔离。

## 回滚方式

将本次提交中 `canvas.js`、`smart-canvas.js` 恢复到上一版本即可；增量开关也可先置为 `false`，由既有全量渲染路径继续提供功能兜底。未改变节点、连接、媒体、输入法、同步或撤销重做数据结构。
