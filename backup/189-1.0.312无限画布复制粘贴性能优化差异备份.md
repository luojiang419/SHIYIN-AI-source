## 经典画布

修改前：

```javascript
const toCopy = [...selected].map(id => nodes.find(n => n.id === id)).filter(Boolean);
const pickedConnections = connections.filter(c => ids.has(c.from) && ids.has(c.to));

setTimeout(() => {
    if(lastImagePasteAt >= requestedAt) return;
    pasteNodes();
}, 90);

connections.push(...newConnections);
sanitizeConnections();
syncGeneratorInputs();
```

修改后：

```javascript
selectedIds.map(id => canvasNodeIndex.get(id))
    .forEach(node => collectClassicClipboardNode(node, toCopy, ids));
const pickedConnections = classicClipboardConnections(ids);

scheduleClassicNodePasteFallback(); // 真实 paste 事件优先，0 ms 回退

const appendedConnections = appendValidatedPastedConnections(newConnections);
syncGeneratorInputs(affectedGeneratorIds);
```

- 复制组节点时递归收集成员并去重。
- 粘贴组成员只保留 `idMap` 中成功重映射的新 ID。
- 邻接索引使用连接数组来源和数量双重失效判断。
- 系统图片、视频和音频先于内部节点剪贴板处理。

## 智能画布

修改前：

```javascript
const copiedNodes = ids.map(id => nodes.find(n => n.id === id)).filter(Boolean);
const copiedConnections = canvas.connections.filter(c => idSet.has(c.from) && idSet.has(c.to));
setTimeout(() => pasteNodes(), 90);
```

修改后：

```javascript
ids.map(id => smartNodeIndex.get(id))
    .forEach(node => collectSmartClipboardNode(node, copiedNodes, idSet));
const copiedConnections = smartClipboardConnections(idSet);
scheduleSmartNodePasteFallback();
```

- 新增模型级 `nodeId -> connection indexes` 邻接索引。
- 智能组成员、输入节点和连接端点均在粘贴时重映射。
- 系统媒体和素材收件箱优先于内部节点粘贴。

## 测试与真实验证

- 新增 8 项复制粘贴性能契约，覆盖节点索引、邻接索引、同长度数组替换、组成员重映射、局部连接校验、目标生成器同步、0 ms 回退和媒体优先级。
- 经典全选 7 节点粘贴增量 7，7 成员组粘贴增量 8。
- 智能单节点、多选 3 节点、3 成员组粘贴增量分别为 1、3、4。
- 智能系统 PNG 粘贴在内部剪贴板含 4 节点时只新增 1 个媒体节点。
- 所有节点粘贴在 150 ms 后均无二次增长；新旧组成员集合不相交且成员全部存在。
