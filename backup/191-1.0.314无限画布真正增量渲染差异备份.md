日期：2026-08-26

基线：`main@40f682c` / `1.0.313`

目标版本：`1.0.314`

范围：模块 4，仅记录经典与智能无限画布节点、端口、连接、几何、选择媒体、小地图和复杂拓扑回退的本次差异。模块 5 保存序列化未开始。

## 1. 经典节点与几何索引

改动前：

```text
renderClassicMutation()
  -> 重建 canvasNodeIndex
  -> rebuildCanvasDomIndexes() 扫描全部节点与端口
  -> refreshGeometryAfterLayout() 刷新全部几何和连线
  -> 全根节点图标/媒体绑定
  -> 全量高清图与小地图刷新
```

改动后：

```text
createdIds/removeIds/replaceIds
  -> indexClassicNodeDom()/removeClassicNodeDomIndex()
  -> 只维护目标节点 DOM、端口 DOM、矩形与端口几何缓存
  -> 只对替换节点保留媒体、绑定图标/预览
  -> syncCanvasSelectedImageResolution(..., affectedNodeIds)
  -> scheduleMinimapNodeUpdate(affectedNodeIds)
```

指定节点几何失效不再递增全局 epoch；只有全量失效才清空全部几何缓存。

## 2. 经典连接结构 patch

改动前：结构创建、粘贴或删除后依赖完整 `renderLinks()`，连接更新还可能逐项扫描 `connections.find()`。

改动后：

- mutation 携带 `createdConnectionIds`、`removedConnectionIds`、`affectedConnectionIds`。
- 新增、删除和相邻连接只更新对应 path、hit 与控制点 DOM。
- `classicConnectionModelIndex` 提供稳定模型查找，空连接层也可局部插入第一条连接。
- 索引缺失或结构 dirty 时由 `fallbackClassicRenderMutation()` 输出原因并完整 `render()`。

## 3. 智能节点、模板与分组索引

改动前：智能 mutation 仍扫描全部 `.image-node`、采集全画布媒体状态、重建连接 SVG 和全部 DOM/几何索引；完整与增量渲染各维护一份节点模板。

改动后：

- `indexSmartNodeDom()` / `removeSmartNodeDomIndex()` 只维护目标节点、端口、矩形和端口几何。
- 完整与增量渲染统一复用 `smartNodeHtml()`，分组 DOM 继续位于成员之前。
- `commitSmartNodeCreate()` 统一菜单节点的模型索引、选择、mutation 与保存提交。
- `smartGroupOwnerIndex` 维护成员归属；成员重索引保留 owner，分组重索引清理并重建其成员映射，真实删除清理 owner。
- 删除分组成员时，存活分组同步加入 `replaceIds`，避免 `group.items` 已更新但分组 DOM 仍陈旧。

## 4. 智能连接稳定 ID 与局部 SVG

改动前：旧连接可能没有 ID，普通操作也重建完整 SVG；连接选择依赖易漂移的数组下标，空 `data-conn-index` 可能被当成索引 0。

改动后：

- `ensureSmartConnectionIds()` 为旧连接补稳定 ID；创建、粘贴和 Alt 拖拽连接始终生成新 ID。
- 普通一对一连接按 ID 局部创建、删除或更新 path、hit、dot、cut。
- 连接选择优先使用 `data-connection-id` 与 `smartConnectionModelIndex`；只有分组合并线回退合法非空数组下标。
- 分组合并线、历史线、级联运行、插入预览或索引 dirty 输出 `console.warn`，并明确回退完整连接层。

## 5. 智能分组连续历史补强

改动前：分组菜单创建成员只记录新成员节点，既有分组的 `items` 原地变化未进入事务；事务字段替换撤销还错误应用 `change.after`。

改动后：

```text
createNodeFromMenu(groupId)
  -> 只克隆 smartNodeIndex 中目标分组 before
  -> 入组成功
  -> 只克隆同一分组 after
  -> commitSmartHistoryTransaction(..., {replacedNodes:[{id,before,after}]})
```

双画布 `apply*HistoryTransaction()` 均改为应用 `change.before`；重做继续通过反向事务恢复原 `after`。没有恢复 `cloneSmartHistoryValue(nodes)`、`snapshotForUndo()` 或整画布同步深拷贝。

## 7. 真实 Chromium 验收

经典 500 节点/1000 合法连线：

- 创建、撤销、重做；合法内部连接粘贴；删除与撤销/重做均保持数组、模型索引和 DOM 数量一致。
- 故障注入捕获 `[canvas] 增量渲染失败，回退完整 render`。

智能 500 节点/1000 连线：

- 创建、粘贴、删除、撤销/重做均通过；新连接 path/hit/dot/cut 使用同一稳定 ID。
- 分组复杂拓扑捕获 `[smart-canvas] 复杂连接拓扑回退完整 SVG： group-or-history-node`。
- 分组连续历史节点序列为 `500 -> 501 -> 502 -> 501 -> 502 -> 501 -> 502 -> 501 -> 500`，连线全程 1000。
- 成员存在时 `group.items` 与 owner 均正确；删除或撤销创建后两者均清空；重做可恢复。
- 控制台 0 error；既存 Lucide `badge-hd` 缺失图标警告不属于本模块。
