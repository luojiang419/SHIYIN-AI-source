# 1.0.315 无限画布模块 5 真实媒体性能验收差异备份

## 变更范围

本备份记录模块 5（经典/智能无限画布真实媒体大画布性能验收）的源码、专项测试、方案文档和避坑记录。模块 0-4 已在前序备份中完成，本次不重复记录。

## 1. 经典图片节点几何回填

文件：`static/js/canvas.js`

```javascript
// 变更前
requestAnimationFrame(refreshGeometry);
loadedImg.onload = () => refreshGeometryAfterLayout();

// 变更后
scheduleClassicNodeRectMeasure([node.id]);
loadedImg.onload = () => scheduleClassicNodeRectMeasure([node.id]);
```

影响：图片缓存命中和异步加载均只测量新建节点，局部失效目标端口几何、相邻连接和小地图节点；不再因单张图片加载刷新整张画布几何或完整连线层。

## 2. 经典视觉壳与增量 LOD

文件：`static/js/canvas.js`、`static/css/canvas.css`

```text
变更前：节点标题、body、边框、阴影和端口共同参与外层节点绘制；选择/结构 mutation 后 LOD 全量遍历全部节点。
变更后：标题/body/视觉背景进入 .node-visual-shell，端口和 resize handle 保留为 .node 直接子节点；选择/结构 mutation 只合并受影响节点 ID，视口/拖动/缩放仍保留全量精确路径。
```

影响：1500/2000 节点场景的悬浮创建不再触发全量 LOD DOM 访问；端口交互结构不被 paint containment 裁剪。

## 3. 智能 Composer 防抖

文件：`static/js/smart-canvas.js`

```javascript
// 变更前：每次 smart mutation 同步 updateComposer()
renderSmartMutation(mutation);
updateComposer();

// 变更后：结构操作静默 600ms 后在空闲期合并更新
renderSmartMutation(mutation);
scheduleSmartComposerUpdate();
```

`scheduleSmartComposerUpdate()` 可取消前一轮 timer/idle callback，等待 600ms 操作静默后使用 `requestIdleCallback({timeout:1200})`，普通选择和完整 render 仍即时更新。

## 4. 智能批量结构历史事务

文件：`static/js/smart-canvas.js`

```javascript
// 变更前：批量创建路径会对 2000 节点全量 pushUndo()
pushUndo();

// 变更后：只记录本次结构差异
const historyTx = beginSmartHistoryTransaction('toolbar-batch');
// commitSmartNodeCreate + 新连线 + 局部 mutation
commitSmartHistoryTransaction(historyTx);
```

异常通过 `abortSmartHistoryTransaction()` 回退未完成事务；撤销/重做仍保留节点、连线和选择语义。

## 6. 真实生产环境验收摘要

- 经典/智能 500、1000、1500、2000：模型节点数与 DOM 节点数一致，真实图片全部加载，使用 6 个真实 `/assets/input/...` URL，0 连线基线保持正确。
- 1000 节点以上 A 档：直接操作 p95 `<=150 ms`、p99 `<=200 ms`，不得出现 `>100 ms` 主任务或二次冻结；完整 render、全量连线重绘、结构、图标、端口、撤销、保存和媒体真实性为硬约束。
- 智能 2000：首次冷启动批量 Long Task 331ms（用户确认的单次 `<=350 ms` 例外）；稳态粘贴 p95 72.3ms、批量处理 p95 86.8ms/p99 87.4ms、Long Task 0。
- 智能批量事务真实序列：2001/1 → 撤销 2000/0 → 重做 2001/1；保存重载后恢复 2000/0，undo/redo 为空。
