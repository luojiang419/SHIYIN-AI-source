## 关键差异

1. 后端 `normalize_provider`：将 `ecommerce-vision` 从视觉专用集合移除，保留图片/聊天/视频模型及用户选择的协议；`local-vision` 行为不变。
2. 后端 `merge_default_api_providers`：电商默认平台合并时不再清空图片/视频模型或强制覆盖协议，刷新后保留用户配置。
3. 前端 `isVisionProviderId`：只识别 `local-vision`，电商平台显示普通 API 配置区块；电商 ID 仍列入内置/不可删除平台集合。
4. 前端模型标题恢复通用文案，只有本地视觉平台显示视觉专用提示。
