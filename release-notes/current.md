# SHIYIN AI v1.0.124

- 作品库搜索升级为 SQLite FTS5 全文索引，百万级作品关键词搜索 p95 降至约 3.14ms。
- 作品库、画布列表和本地素材索引保持百万级分页性能，压测脚本新增 median/p95/max 指标。
- 新增媒体引用计数扫描，可重建 `media_objects` 引用计数并识别孤立内部文件。
- 新增孤立内部媒体 dry-run 与宽限期清理能力，默认只清理 input/output 内部文件，不自动删除用户上传素材。
- 软件设置页新增“存储维护”面板，可刷新汇总、扫描引用、预览孤立文件并确认清理。
- 发布前完成本地测试、安装包构建、安装包校验和 GitHub Release 远端复核。
