# SHIYIN AI v1.0.273

- 页面入口、登录页、管理页及直接访问的画布 HTML 统一设置为不存储缓存；刷新后会重新请求最新页面，避免旧页面壳滞留。
- 静态 JS、CSS 等资源仅在 URL 带 `v=` 版本参数时采用一年不可变缓存；无版本资源仍会重新校验，保留快速加载同时避免手工替换文件后持续显示旧内容。
- 生成媒体缓存按当前 Service Worker 版本隔离，升级后自动移除旧缓存；预览接口和未带内容修订号的图片改为网络优先、离线时回退缓存，避免同 URL 生成结果被旧图遮蔽。
- 新增单个生成媒体缓存失效接口，并补充 HTML、静态资源和 Service Worker 缓存策略回归测试。
