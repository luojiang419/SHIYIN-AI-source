# SHIYIN AI v1.0.143

- 普通无限画布新增多宫格图片自动识别，可按识别结果拆分，并通过横纵标尺精确调整裁切边界。
- 新增 Blender 3D 导演节点，支持自动发现或启动 Blender、无配对码本地鉴权、相机参数控制、静帧与动画渲染回传。
- Windows 安装器可选安装或更新 Blender 连接插件，并保持现有用户数据和配置不变。
- 普通画布、画布列表和智能画布全面移除旧蓝黑主题来源，节点、输入框、媒体缩略图、弹窗、滚动条、焦点环和交互状态统一为中性灰与品牌暖棕。
- 三个画布页面不再加载旧 `theme.css`，并增加新的静态资源缓存版本，避免升级后继续显示旧蓝色样式。
- 新增严格色相回归检查，自动阻止蓝色、青色、靛蓝和低饱和蓝灰色重新进入画布界面。
- 完整 Windows 安装包继续执行后端健康、单实例、父子进程退出和安装产物版本校验；本版全量自动化测试 287 项通过。
