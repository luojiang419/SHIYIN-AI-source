# SHIYIN AI v1.0.112
- 修复所有文本输入框在打字时失焦的问题，中文输入法候选字不再因为页面重绘或程序化 `blur()` 被取消。
- 新增全局输入法焦点守卫，覆盖主壳、普通画布、智能画布、电商/自由创作、设置页、素材页、作品页和聊天页。
- 普通画布、智能画布、电商/自由创作在输入法组合期间会延后替换输入控件 DOM，并在重绘后恢复焦点和光标位置。
- 电商/自由创作入口、页面资源缓存版本继续保持同步，避免一个入口更新后另一个入口仍加载旧脚本。
- 生成任务缩略图栏继续显示与请求数量一致的 pending 占位和计时状态。
- 更新器安装阶段继续隐藏辅助命令行窗口，并保留安装器实时进度显示。
