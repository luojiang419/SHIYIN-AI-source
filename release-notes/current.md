# SHIYIN AI v1.0.136
- 两种无限画布均新增 MiniMax H3 视频生成节点，内置连接已部署的 H3 服务地址。
- 支持文生视频、单首帧、首尾帧，以及最多 9 张图片和 3 个参考视频的全能参考输入。
- 参考视频音轨会随视频一起提交给 H3，用于动作、运镜、节奏与声音参考。
- H3 节点提供部署端实际可用的 18 档分辨率、1–15 秒时长和 4–30 采样步数。
- H3 参考素材支持画布本地上传、data URL 与远程素材地址，成片自动归档到 SHIYIN AI 作品输出。
- 修复全能模式“模特主体 + 模特形象 + 产品”错误跳过主体图、改用模特形象图背景的问题。
- 模特形象现在严格只提供脸部；主体图继续提供身体、发型、背景、光线与无动作参考时的原姿势，产品图只提供产品本体。
- 有动作参考时，最终结果固定为主体图身体换上模特形象脸部、穿着指定产品，并在主体背景中执行参考动作。
- 移除全能模式底部的自动组合方案提示横幅，其他共享页面也不再显示此类被动信息横幅。
- 全能模式的姿势证据现在只允许来自“动作参考”或“模特主体”；两者同时存在时，动作参考是唯一且最高优先级姿势来源。
- 模特主体、商品和动作参考同时存在时，生成结果固定为主体模特穿着指定产品并执行动作参考姿势，商品图中的人物动作不再参与生成。
- 划像对比改为优先显示动作参考与生成图；没有动作参考时才显示模特主体，不再使用商品、细节、场景或风格图参与划像。
- 修复全能模式“模特主体 + 下装”错误继承下装参考图人物动作、场景、镜头和构图的问题。
- 下装参考图现在只提供下装商品本体；模特身份、身体、姿势、背景、光线与所有非下装区域严格保持主体图不变。
- 修复上一轮仅交付 Tauri 裸宿主、脱离后端侧车与 Web 资源后无法运行的问题。
- 默认桌面构建现在直接生成完整 Windows 安装包，不再把内部宿主文件当作可分发版本。
- 安装包封装前强制启动完整分阶段目录，自动验证后端健康、数据目录、单实例和父子进程退出。
- 安装器回归新增安装后实际启动检查，文件存在但应用无法运行时不允许通过发布验证。
- 全能模式无提示词生成改为四路方案：主体局部编辑、可见模特穿搭、无人物三维穿搭与纯商品展示。
- “模特主体 + 服装”现在只替换主体服装，原模特、背景、动作、机位和构图保持不变。
- “服装 + 动作”且没有人物参考时，生成无脸、无皮肤、无模特的高级三维穿着状态。
- 仅商品或商品加场景时生成平铺、悬挂、商品英雄图或场景化商品图，不再自动补人物。
- 手动填写提示词时只提交用户原文并保留上传顺序，不叠加内置规则、类型重排或自动视觉分析。
- “细节图”扩展为“商品补充/细节图”，可承载平铺、背面、局部和材质等商品证据。
