# SHIYIN AI v1.0.311

- 优化经典无限画布右键和节点菜单的显示热路径：创建、连线、端口、图片和输出菜单只刷新自身图标，不再扫描整页 DOM；该成本不再随画布节点数量放大。

- 经典创建菜单由两次同步布局读取降为一次最终矩形读取，继续保留单双列切换、视口夹紧和子菜单翻转；经典菜单、子菜单、图片悬浮功能栏及智能创建菜单移除高成本背景模糊，改用不透明主题背景。

- 新增 5 项菜单性能专项契约，并通过 51 项画布相关回归、双画布 JavaScript 语法检查及真实 Chromium 菜单显示验证；测试服务、QA 画布和临时目录已清理。

- API 设置新增 `Responses（原生）`协议、Responses 端点配置、模型列表获取和端点探测；上游未提供 `/v1/models` 时会保留手动填写模型的入口。

- AI助手节点支持通过 Responses 原生接口调用视觉模型：系统提示词转换为 `instructions`，文本与历史消息转换为 `input`，图片转换为 `input_image`，并兼容标准 `output_text` 响应解析。

- 原“LLM 节点”用户可见名称统一为“AI助手”，覆盖经典画布、智能画布、API 设置和相关中英文提示；内部节点类型保持兼容，不影响已有画布。

- 移除无限画布中的“一键创建电商工作流”节点组及组级输入/输出端口、拓扑运行逻辑；保留电商模特、产品、场景、A+ 图合成、电商视频五个独立节点，以及普通图片组能力。

- 修复电商工作流独立节点输入端口和图片上传容错。

- 经典画布中的 LLM 节点已统一更名为“AI助手”，并同步到工具栏、创建菜单、节点标题、连线创建菜单和相关提示；经典画布与智能画布均已移除循环节点的新建入口，同时保留历史循环节点运行兼容。

- 优化智能画布节点悬浮功能菜单首次显示：单击选中不再延迟 220ms，选择反馈与高清预览只更新受影响节点，菜单取消高成本背景模糊并刷新静态资源缓存版本。

- 修复灯光重塑与角度调整节点连接图片后预览不稳定、生成结果只出现在作品管理而不创建输出节点的问题；生成完成会自动创建并连接下游输出节点。
- 两个节点新增分辨率、质量、输出画幅和可选模型覆盖控制，并将参数实际传入图片生成任务。
- 角度调整预览固定参考图与主体在中心，仅移动摄影机轨迹和机位标记，不再随参数旋转参考图。

- 兼容 Windows 桌面 WebView2：无限画布输出节点“下载全部”在不支持 File System Access API 时改用原生文件夹选择器，选择一次目录后逐个写入真实文件，仍不生成 ZIP。

- 无限画布输出节点右键“下载全部”改为选择目标文件夹后逐个保存真实文件，不再生成 ZIP；素材库画布资产首次进入自动加载，并在画布数据变更后自动联动刷新。

- 修复作品管理和画布资产“打开目录”在 Windows 路径包含空格时错误打开“文档”目录的问题。Explorer 现在收到完整且兼容的 `/select,"真实文件路径"` 命令行，真实路径解析失败时仍返回明确错误，不再静默兜底到默认目录。

- 优化作品管理多选性能：拖拽过程中使用 `requestAnimationFrame` 和卡片增量样式同步，不再每次鼠标移动都重建图片/视频卡片与事件监听。
- 优化批量删除体验：删除请求期间保留作品列表并锁定批量按钮，完成后直接从当前列表移除已删除作品并同步数量，不再黑屏或依赖手动刷新。

- 作品管理新增显式“多选”开关和卡片复选框；开启多选后无需按 Shift 即可点击选择或拖拽框选，Shift 快捷方式保留并补充按键状态监听，避免桌面 WebView 丢失修饰键状态。

- 作品管理支持按住 Shift 拖拽框选多个作品，顶部显示“收藏、删除、移到回收站、取消选择”批量菜单。
- 批量“删除”会永久删除真实本地媒体文件并移除作品记录；“移到回收站”只标记状态、保留文件，二者行为明确分离。
- 修复作品视频预览非全屏状态按空格先触发全屏按钮的问题：预览对话框打开且视频可见时，空格直接播放/暂停，只有手动点击全屏按钮才进入全屏。
- 作品视频全屏预览支持按空格键播放/暂停；拦截全屏时的默认空格行为，避免页面滚动或一次按键重复切换。
- 修复作品预览中隐藏的图片层覆盖视频：`hidden` 图片不再被预览缩放样式强制显示，视频画面和播放控件可直接点击。
- 补强旧作品/画布资产的媒体类型识别：即使 URL 没有扩展名，只要展示文件名为 `.mp4` 等视频格式，也会使用视频播放器，不再错误渲染为破图。

- 修复作品管理与画布资产页面视频在桌面 WebView 中无法播放：本地/远程视频统一经后端流式代理，支持 Range 分片与正确 MIME 类型。
- 画布资产详情新增“打开目录”，按当前账号解析真实文件路径并调用系统文件管理器；远程同名文件不再被错误定位。
- 更新作品与资产脚本缓存版本，升级后立即使用修复代码。

- 覆盖安装不再弹出“目标目录已存在”确认框，安装器会直接进入安装流程。
- 覆盖安装继续只替换 `{app}\app` 程序目录，保留 `{app}\data` 中的 API 配置、数据库、画布与日志。

- 修复历史视频任务类型未被作品管理识别为视频的问题；作品管理与画布资产统一按实际媒体类型渲染并播放 MP4 等视频。
- 优化智能画布节点上方悬浮菜单的图标刷新范围，避免 460 个节点时点击操作触发全页面扫描造成数秒卡顿。

- 修复作品管理与画布资产中的远程视频无法播放：统一通过后端流式代理传输，兼容 Range 分片与桌面 WebView 的跨域限制；修复历史本机绝对媒体地址，并允许视频预览自动播放。

- 优化影视制作“生成线稿分镜”节点，复用批量处理能力，支持任意数量图片批量并行提交、逐图输出、失败状态和任务恢复。
- 新增影视制作“生成线稿分镜”节点：可连接视频帧/分镜图组，逐帧生成专业线稿分镜，并在节点内设置平台、模型、画幅、分辨率、质量和补充要求。

- 修复作品管理中历史作品与画布资产合并后沿用旧默认文件名，导致多个作品卡片显示相同文件名的问题；最终排序后按真实媒体名重新归一化，并对重复名称做唯一化处理。

- 修复作品管理中同批生成作品共用历史时间的问题，优先显示每个本地文件的真实修改时间，并按媒体文件名展示画布资产。
- 修复“打开目录”无法定位旧版 `exports/generated` 文件及 Windows 路径含空格时 Explorer 参数失效的问题。

- 作品管理与画布资产页统一显示图片、视频生成资产，支持电商与无限画布资产聚合。
- 两个资产页面新增图片/视频筛选与“最早优先/最新优先”排序，最新生成内容在“最新优先”模式下固定显示在顶部，设置会持久化保存。
- 统一 VERSION、npm、Tauri、Cargo 与后端运行时版本号，修复安装后更新器仍把桌面宿主识别为旧版本的问题。

- 修复安装器复用被自动化测试写入的临时目录，导致正式安装落到项目 `.build` 缓存并读取不到原用户 API 配置的问题。
- 正式安装器现在默认安装到 `D:\Program Files\SHIYIN AI`；只有历史目录中存在主程序或用户数据库、且目录不是测试缓存时，才会继续复用真实自定义安装目录。
- 安装与升级仍只替换 `{app}\app` 运行时目录，不删除 `{app}\data`，API 服务商、加密密钥、画布和其他用户数据继续原位保留。
- 安装器进度和更新器 E2E 测试新增正式注册项保护与测试注册项清理，避免测试再次改写用户安装位置或开始菜单入口。
- 全量 `706` 项 Python 测试、`42` 个子测试、Rust 更新器 `5` 项测试及双画布 JavaScript 语法检查通过。
