# SHIYIN AI v1.0.151
- 修复 720°取景器随画布选中、点击和重绘后偶发黑屏的问题：旧 WebGL 纹理、缓冲、程序和上下文会在节点替换前主动释放，浏览器回收上下文后可自动重建并恢复全景纹理。
- DWPose 动作提取节点新增“导出骨架图”；点击后会在右侧自动创建带骨架参考图的专用输出节点并自动连线，可直接继续连接下游。重复导出复用专用节点，不覆盖用户已有的其他输出。
- 特殊节点脚本缓存版本提升为 `special-nodes.4`；完成真实页面 24 次交替点击重绘回归，未出现新增运行期错误；全量自动化测试 331 项、38 个子测试通过。

- 普通无限画布与智能无限画布同步新增“灯光重塑”节点。节点以生成式重打光方式工作，支持上、下、左、右、正面、逆光和轮廓光方向，并可调整色温、强度、柔硬光与自然、影棚、电影、日落、夜景、霓虹氛围。
- 灯光重塑沿用所在画布的默认图片 API 平台和模型，只提交一张源图参考并自动保持源图宽高比；生成结果以标准图片引用回写节点，可继续连接下游图片、视频、LLM、循环和输出节点。
- 用户调整灯光参数时不会自动调用 API，只有点击“生成重塑图”才会提交任务；源图或参数变化后会自动清除不再匹配的旧结果。
- “角度调整”暂不进入本版新建菜单；保留历史画布兼容代码，等待可靠机位后端方案完成后再开放。
- 完成双画布真实页面创建与交互验收；全量自动化测试 329 项、38 个子测试通过，桌面端 `cargo check` 通过。

- 普通无限画布与智能无限画布同步新增 720°取景器节点。产品交互使用“720°”名称，底层采用兼容主流全景工具的标准 2:1 等距柱状全景图，可直接导入，也可调用已配置的图片模型生成完整球面场景。
- 取景器支持拖动改变水平角和俯仰角、滚轮调整 FOV，并提供 16:9、9:16、1:1、4:3、3:4 取景画幅与多档导出尺寸。
- 用户可在选定视角中添加、移动和缩放人偶占位；导出时会把透视视图与人偶合成为一张位置参考图，并作为普通图片引用连接到下游图片、视频或提示词节点。
- 两种画布同步新增 DWPose 动作提取节点。连接或导入人物图片后自动调用本地 DWPose，输出黑底彩色身体、手部和面部骨架图；上游图片变化会触发重新提取，结果可继续连接下游作为姿势参考。
- 新增共享节点样式和双画布特殊节点回归合同；全量自动化测试 323 项、38 个子测试通过。

- 新增 DWPose 本地姿态能力：使用 YOLOX 与 RTMPose ONNX 模型在 CPU 上识别多人身体、手部和面部关键点，不依赖云端 API 或独立显卡。
- DWPose 模型不塞入安装包；软件首次启动在后台自动补齐到 `data/system/models/dwpose`，优先腾讯国内镜像，失败后依次尝试 Windows 系统代理和 Hugging Face 官方源，升级后继续复用。
- 模型下载支持断点续传、临时文件、大小与 SHA-256 双重校验、原子安装和并发去重；国内压缩包安装成功后自动删除，避免重复占用空间。
- 本机管理员页面新增 DWPose 下载状态、进度、来源、失败原因和重新下载按钮；普通局域网账号可以使用本地姿态检测，但不能查看模型目录或管理下载。
- 安装态内置 NumPy、OpenCV Headless 和 CPU ONNX Runtime，移除无关 CUDA/TensorRT 运行库；DWPose/MMPose Apache-2.0 许可与改编说明随安装包分发。

- 局域网 Web 普通账号扩展为中文、英文字母大小写和数字，英文字母大小写视为同一账号；密码仅要求非空，不限制长度或复杂度，首次访问仍可自动注册。
- 已有纯数字账号和独立数据目录会自动兼容升级，每个普通账号继续拥有独立数据库、画布、素材、生成资源、任务和实时同步空间。
- 普通账号的数据归档到 `data/accounts/<内部ID>` 专属目录，HTTP 文件访问、生成任务和 WebSocket 广播均按账号隔离。
- 普通局域网账号只能修改主题和显示语言；API 地址、密钥状态、API 设置、软件设置、运行路径和更新功能均不可见且后端拒绝越权访问。
- 新增仅限安装软件本机使用的管理员页面，管理员 `jiang` / `jiang` 可查看原账号和原密码、修改或重置账号密码、启用或禁用账号，并浏览每个账号的生成媒体、导出文件、素材、作品、画布和项目。
- 普通无限画布新增多宫格图片自动识别，可按识别结果拆分，并通过横纵标尺精确调整裁切边界。
- 新增 Blender 3D 导演节点，支持自动发现或启动 Blender、无配对码本地鉴权、相机参数控制、静帧与动画渲染回传。
- Windows 安装器可选安装或更新 Blender 连接插件，并保持现有用户数据和配置不变。
- 普通画布、画布列表和智能画布全面移除旧蓝黑主题来源，节点、输入框、媒体缩略图、弹窗、滚动条、焦点环和交互状态统一为中性灰与品牌暖棕。
- 三个画布页面不再加载旧 `theme.css`，并增加新的静态资源缓存版本，避免升级后继续显示旧蓝色样式。
- 新增严格色相回归检查，自动阻止蓝色、青色、靛蓝和低饱和蓝灰色重新进入画布界面。
- 完整 Windows 安装包继续执行后端健康、单实例、父子进程退出和安装产物版本校验；本版全量自动化测试 316 项、38 个子测试通过，并完成账号隔离、管理员页面、DWPose 自动下载、真实模型推理和电商 6 类操作回归。
