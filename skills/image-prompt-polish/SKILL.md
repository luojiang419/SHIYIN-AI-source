# Image Prompt Polish

这是 SHIYIN-AI 图片生成节点使用的本地兼容规范。它负责把用户的自然语言需求和参考图证据编译为目标图片模型更容易执行的提示词。

SHIYIN-AI 的所有图片生成节点统一按照 Nano Banana Pro 的自然语言提示词规范编译，不根据平台名称切换为 GPT Image、Seedream、FLUX 或其他图片模型 profile。平台只负责图片 API 传输，节点的规范化目标固定为 Nano Banana Pro。

## 硬约束

1. 用户明确的主体、动作、关系、数量、文字、风格、尺寸意图和否定要求优先级最高。
2. 参考图只提供可见证据。不得把看不清的品牌、文字、身份、材质或背景细节当作事实补全。
3. 多张参考图必须逐张建立角色映射。除非用户明确允许混合，否则不得交换人物身份、服装、商品、姿势、场景或文字归属。
4. 扩展模糊需求时，只补充能让画面可执行的环境、构图、光线、镜头、材质和动作细节，不改变原始事件或主题。
5. 品牌、广告、lookbook 和艺术风格只能提取公开案例中的高层视觉方法；不得复制具体作品的主体、文案、独特构图或受保护角色。
6. 输出只包含最终图片提示词，不输出思考过程、网页原文、搜索过程、API 参数猜测或 Markdown 代码块。
7. 禁止堆叠 `8k`、`masterpiece`、`best quality`、`highly detailed` 等不能表达具体画面关系的泛化质量词。

## 优化维度

按请求需要选择维度，不要为了完整而机械填满每个字段：

- 用户意图和最终画面类型
- 主体、外观、动作、姿态、视线和主体关系
- 场景、时间、天气、空间层次和环境因果
- 构图、景别、视角、主体位置和留白
- 光线方向、光质、色彩关系和接触阴影
- 镜头感、焦段倾向、景深和视觉叙事
- 服装、产品、材质、纹理、透明度和可见文字
- 参考图角色、保留区、修改区和不可改变项
- 必要的排除约束

## 推荐最终结构

```text
最终画面意图：...
主体与动作：...
场景与环境：...
构图与镜头：...
光线与色彩：...
风格与材质：...
参考图关系：...
文字与保留约束：...
排除约束：...
```

profile 只决定结构和兼容性，不会覆盖用户选择的图片 provider/model，也不应让图片模型再次自由改写已经编译好的提示词。
