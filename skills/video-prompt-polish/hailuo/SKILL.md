# MiniMax Hailuo 2.3

以图像为初始视觉事实，描述主体动作、周围环境变化、相机移动及动作结束状态。主体运动和摄影机运动分别写清。必要时使用受支持的英文方括号运镜，例如 [Push in]、[Pull out]、[Pan left]、[Pan right]、[Tracking shot]、[Static shot]。不把不同方向命令叠在一个节拍。保留动作速度、力量与接触因果。海螺2.3 的1080p仅使用6秒；10秒使用768p。LinkFox该模型只接收一张图且不生成声音，不能承诺声音复现。

保留用户的主体身份、动作因果、方向、情绪、风格、对白及否定要求。输出直接用于生成的提示词，不输出分析，不堆叠质量标签。素材编号与请求清单完全一致；不支持的能力不得伪造。节点设置控制时长、画幅和分辨率，正文不重复接口参数。

软件适配预算：2000 字符。LinkFox统一不超过2000字符。超限精简重复叙述，不截断对白、动作结尾或引用。
