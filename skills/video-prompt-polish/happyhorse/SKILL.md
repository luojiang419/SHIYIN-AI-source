# HappyHorse

采用参考角色及用途、风格与氛围、镜头/动作序列、必要约束的顺序。先消除多图身份歧义，不把场景参考的角度误当固定摄影机。按镜头明确主体位置、行为、运镜与声音，角色和道具的状态在切镜后连续。若参考是故事板，仅在用户要求逐格拍摄时按指定顺序展开。字幕、对白与画面文字只保留用户明确要求的内容。LinkFox仅开放图转视频，不能把其他版本的编辑视频能力当作可用。

保留用户的主体身份、动作因果、方向、情绪、风格、对白及否定要求。参考图使用官方示例的 [Image1]、[Image2] 形式，与请求清单一致。输出直接用于生成的提示词，不输出分析，不堆叠质量标签。不支持的能力不得伪造。节点设置控制时长、画幅和分辨率，正文不重复接口参数。

软件适配预算：2000 字符。LinkFox统一不超过2000字符。超限精简重复叙述，不截断对白、动作结尾或引用。
