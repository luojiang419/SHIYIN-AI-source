# Seedance 2.0 / Fast

说明参考图用于身份、场景、风格或首尾帧，再以清楚的空间关系和按时间推进的动作组织镜头。明确起始画面、运镜方向、动作结果以及必要声音。多镜头需保持人物、道具、光线连续，不凭素材数量增加切镜。Fast 与标准模型保留相同创意，按实际时长控制动作密度。只能使用请求清单的图片/视频/音频引用；LinkFox 图转视频不接受直接视频/音频输入。

保留用户的主体身份、动作因果、方向、情绪、风格、对白及否定要求。输出直接用于生成的提示词，不输出分析，不堆叠质量标签。素材编号与请求清单完全一致；不支持的能力不得伪造。节点设置控制时长、画幅和分辨率，正文不重复接口参数。

软件适配预算：2000 字符。LinkFox统一不超过2000字符。超限精简重复叙述，不截断对白、动作结尾或引用。
