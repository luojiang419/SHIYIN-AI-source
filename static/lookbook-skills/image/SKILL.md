# Lookbook 内置视觉 Skill

本目录把 [smixs/visual-skills/image](https://github.com/smixs/visual-skills/tree/main/image)
的可执行原则映射为 Lookbook 内置风格：按模型选择自然语言提示词，先描述主体与场景，再补充布光、材质、构图、用途和约束；系列图保持身份、商品比例、Logo 与版式留白一致。

内置卡片覆盖商业产品摄影、时尚编辑、美妆广告、海报插画和社交媒体视觉等 pattern。完整模型规则与参考文件请查看上游仓库。
