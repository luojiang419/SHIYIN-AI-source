# 李维斯广告·环境自适应纪实

## 定位

这是一个从公开广告视频中提炼的可迁移视觉方法预设，不复制原片人物、Logo、文案、地点或独特构图。它把丹宁材质、真实生活动作、人物叙事和环境摄影组织为一套可执行的平面广告语言。

## 执行顺序

1. 先读取人物、商品和场景参考图的事实，只保留可见内容。
2. 锁定参考图所有权：人物负责身份、身体、发型和可见造型；商品负责 SKU 结构、面料、Logo 与文字；场景负责空间几何、天气线索、已有平面图形和环境色。
3. 从场景判断 `interior/exterior`、天气、时间点和主光源，再选择唯一的光线分支。
4. 为每张图指定一个场景内的外部任务和一个可观察情绪。视线必须跟随任务目标，手指形成真实抓握，肩髋负责平衡，脚步与衣料响应运动；双手只有在参考图提供对象时才被物件、服装、工具、商品或环境接触占用，不用摸头发、扶胸或扶脸代替表演。
5. 保持四张输出为四次独立生成：环境建立、动作经过、情绪近景、服装/商品材质细节。

## 环境光线规则

| 场景事实 | 光线与色彩执行 |
| --- | --- |
| 晴天室外 | 方向明确的日光、硬边投影、天空/地面反射补光、暖色高光，保留阴影细节 |
| 阴天室外 | 宽而偏冷的天光、柔和低对比、皮肤保持中性，环境颜色不被灰雾抹平 |
| 雨天或湿地 | 灰色环境光、地面和玻璃的克制反射、湿布料重量与水珠，避免过度镜面效果 |
| 蓝调时刻 | 冷色环境曝光，窗户/路灯/室内实景灯对脸部和丹宁提供暖色动机 |
| 夜间室外 | 只使用现场可解释的街灯、车灯、橱窗或招牌光，深色可读，不把画面压成纯黑 |
| 室内窗光 | 保留窗光方向，同时融合原场景已有灯具，控制混合色温，不使用无来源棚灯 |

## 视觉锁

- 色彩从用户场景采样：约 60% 环境与丹宁中间调、25% 皮肤与中性服装、15% 受控强调色；红色只在场景可见或用户明确要求时使用。
- 摄影机以宽环境建立、人际距离动作中景、亲密情绪近景和材质接触特写组成系列；机位保持眼平或腰平，可有轻微手持偏差、非中心构图和真实前景遮挡。Nano Banana 执行 prompt 不使用数字焦段。
- 造型保留用户可见的服装、鞋包、配饰和妆发；只做天气与动作造成的自然状态变化，不擅自换装、加妆或改变身份。
- 保留丹宁经纬、洗水、车线、铆钉、磨损、折痕、发丝、皮肤纹理、灰尘、水珠和接触阴影。
- 后期使用克制的有机颗粒、自然运动柔化、柔和高光滚降和极轻 halation；当前轻量颗粒强度为 `0.025`，颗粒不能形成片状云斑、重复纹理、明显数字噪点或吞噬皮肤/针织/丹宁细节。

## 失败防护

禁止白底电商站姿、孤立抠图、静止证件照、随机棚拍、无来源渐变、塑料皮肤、CGI 光泽、HDR 锐化、无动机霓虹、场景替换、身份串线、多张拼图和复制参考广告的主体内容。
