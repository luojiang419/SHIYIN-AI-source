# 参考图真实感 Lookbook Skill

## 目标

把“没有 AI 感”拆成可执行的参考图编排规则：让模型从多张人物、商品和场景图学习事实与关系，再生成一组像真实摄影师抓拍的连续画面。该 Skill 不复制任何博主的素材、品牌、文案或平台界面。

## 核心方法

1. **参考图优先**：人物图只负责身份、脸、肤色、发型、体态、服装和随身配饰；场景图负责空间、建筑、光线与可识别环境；商品图负责唯一 SKU、材质、颜色、Logo 和文字。
2. **允许多人物**：多张人物参考图代表不同的人，不要平均脸或混合身份；每个人都要保留独立身份，并在同一空间中建立视线、距离、触碰、走动、倚靠或递物等关系。
3. **零提示词默认**：创作需求为空时，不补写一段泛化的“高级、8K、电影感”提示词；直接以参考图和风格 Skill 作为创作来源，生成一组有变化的生活化画面。
4. **动作代替摆拍**：优先使用决定性瞬间、自然重心、微表情、衣摆/发丝轻微运动、前景遮挡、真实接触阴影和环境互动，避免证件照式站立、对称摆拍和孤立抠图。
5. **系列而非单张**：保持人物身份、服装、商品、场景和调色连续，只改变景别、机位、裁切和瞬间；禁止把输出做成 contact sheet、拼贴或分屏。

## 反 AI 感检查

- 是否能看出人物与场景的真实尺度、脚底接触和光线方向？
- 多人物是否在互相看、听、触碰或共同操作，而不是各自看镜头？
- 是否保留真实皮肤、发丝、织物纹理和轻微不完美，而不是塑料皮肤或过度锐化？
- 是否有具体的环境线索、拍摄时刻和构图选择？若没有，重做该帧。
