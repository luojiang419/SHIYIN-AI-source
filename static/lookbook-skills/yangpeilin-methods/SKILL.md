# 参考图驱动时尚视觉方法 Skill

该 Skill 把杨沛林yppl公开作品中反复出现的制作方法抽象为可执行规则，不复制任何视频画面、品牌、文案、平台界面或第三方资产。

## 核心规则

- 先建立参考图关系：人物、商品、场景、动作和材质各自有明确所有权。
- 用多张参考图代替长篇散装提示词；创作需求为空时直接从参考图推断拍摄情境。
- 用情绪、动作、人物关系和环境接触制造生命力，避免静态棚拍和孤立抠图。
- 输出一组连续画面，保持身份、服装、商品、环境和色调稳定，只改变机位、景别和决定性瞬间。
- 保留皮肤、发丝、织物、金属和玻璃的真实纹理，并检查透视、尺度、遮挡、接触阴影和解剖逻辑。

## 适用类型

多人互动、单人情绪、运动动态、休闲随拍、街头叙事、旅行环境、商品情境、宠物时尚和材质特写。

来源为抖音博主“杨沛林yppl”主页公开作品的标题与画面观察，主页显示 28 条作品。该文件是方法论总结，不是对原作者提示词或作品的逐字转载。

## 2026 FW 参考片视觉复刻层

当用户提供与 2026 FW 参考片相近的视觉目标时，额外启用以下可迁移参数；它们描述摄影语言，不复制片中人物、文案、品牌或具体地点：

- 色彩脚本：暖象牙/奶油白/浅柠檬黄为主场，褪色青蓝为互补环境色，肤色保持暖中性；抬升黑位、开放中间调、奶油高光滚降，避免灰雾和过饱和。
- 光线：高亮自然日光或薄云天光，天空/地面反射补阴影；白色服装和面部保留高光细节，亮边只加轻微暖色 halation。
- 摄影机：手持人眼或腰部高度，倾斜/横置地平线、非中心主体、栏杆/门框/床品/衣摆做前景遮挡；广角环境、中景动作、近景情绪和材质细节交替。
- 人物：用躺卧、倚靠、转身、低头、闭眼微笑、手指搭靠、整理衣物和半步移动表达呼吸与情绪；每张图必须有可观察的微动作，禁止电商站姿。
- 材质与后期：保留皮肤毛孔、发丝、针织线圈、褶皱和金属边缘；加入细腻有机 16mm/35mm 颗粒、轻微印刷扫描质感和低强度锐化，禁止塑料皮肤、HDR 脆边、压黑和过度虚化。
- 系列节奏：从阳光环境建立 → 被观察到的动作 → 私密停顿 → 织物/商品触感证据，保持同一色彩关系与光线方向，只改变机位、裁切和决定性瞬间。
