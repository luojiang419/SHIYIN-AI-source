# 参考图驱动时尚视觉方法 Skill

该 Skill 把杨沛林yppl公开作品中反复出现的制作方法抽象为可执行规则，不复制任何视频画面、品牌、文案、平台界面或第三方资产。

## 核心规则

- 先建立参考图关系：人物、商品、场景、动作和材质各自有明确所有权。
- 用多张参考图代替长篇散装提示词；创作需求为空时直接从参考图推断拍摄情境。
- 用情绪、动作、人物关系和环境接触制造生命力，避免静态棚拍和孤立抠图。
- 输出一组连续画面，保持身份、服装、商品、环境和色调稳定，只改变机位、景别和决定性瞬间。
- 保留皮肤、发丝、织物、金属和玻璃的真实纹理，并检查透视、尺度、遮挡、接触阴影和解剖逻辑。

## 适用类型

多人互动、单人情绪、运动动态、休闲随拍、街头叙事、旅行环境、商品情境、宠物时尚和材质特写。
