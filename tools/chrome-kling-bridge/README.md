# 拾影 · 可灵画布助手 0.2.0

桌面与本机 Web 无限画布选择可灵视频 3.0 Omni，连接图片/视频、填写提示词，点击“生成”或“发送到可灵并生成”。画布自动打开 Chrome 交接页，扩展接收任务后关闭交接页，上传素材、绑定原生引用、同步时长/分辨率/比例/音画同步，最后单次点击生成。

## 安装与使用

1. 在 Chrome 扩展管理开启开发者模式，加载此文件夹（包含 manifest.json）；不要直接加载 ZIP。
2. 升级时点击扩展卡片的刷新图标。保持 Chrome 中的可灵账号已登录。
3. 使用包含新后端与前端的拾影桌面或 Web 画布。无需打开插件弹窗，不需要在 Chrome 再次登录拾影；地址随任务自动传入，不固定使用 3000。
4. 查看画布提交回执。submitted 表示可灵页面出现与提示词匹配的新任务，生成进度与成片暂在可灵查看。unknown 表示已经尝试提交但没有确认回执，必须先核对可灵历史记录，不能直接重发。

本次开发 Web 在 http://127.0.0.1:13170；源码桌面实例自动选用 13171。安装版需要后续发布含后端的热更新才获得这些接口，本轮未发布。

## 范围和保护

- 自动网页生成支持视频 3.0 Omni；其他可灵模型保留原 CLI 生成流程。
- 支持本机 Chrome、localhost 与 127.0.0.1 的任意端口。远程 LAN/公网 Web 来源不在本扩展当前授权范围内。
- 上传 PNG/JPEG、MP4/MOV，单文件最多 200 MB、最多 10 个文件；网页限制不满足时停止。
- 每次仅生成一条视频。参数不可用时不使用网页旧值偷偷提交。
- 每个任务独立随机短期凭据；扩展只可领取该任务、读取该任务素材及回传结果，不取得桌面登录 Cookie。凭据不出现在普通状态查询中。
- 队列在内存中，后端重启后失效，最多保存一小时。上传超时、提交回执丢失都不自动重放生成点击。
- 同一素材组可复用；已有人工草稿时停止，不覆盖。提交前再次校验提示词、素材和生成按钮，后端原子许可与页面单次标记共同防止重复点击。
- 插件弹窗保留手动连接作为旧画布备用入口。新版画布发送会自动接收。
