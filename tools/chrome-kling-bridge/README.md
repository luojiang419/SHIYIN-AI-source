# 拾影 · 可灵自动填充

将普通视频节点、影视视频节点的提示词、图片和深度视频发送到已登录的可灵 Omni。插件上传素材、等待网页返回素材缩略图，再使用原生 `@` 菜单绑定“图片1 / 视频1”等标签。**所有入口只填充，不点击生成。**

## 安装与使用

1. 运行包含本次代码的拾影后端；旧进程需要重启才能加载新接口。
2. 在 Chrome 打开 `chrome://extensions`，开启开发者模式，加载此目录。
3. 在同一 Chrome 中打开拾影本机地址，例如 `http://127.0.0.1:3000`，登录与画布相同的拾影账号。地址必须与插件设置一致，`localhost` 和 `127.0.0.1` 的登录会话互不通用。
4. 点击插件，填写本机地址，点击“连接并接收草稿”。插件每 30 秒检查一次；再次点击连接会立即检查。
5. 在画布的视频节点选择可灵，连接本地图片、视频，输入提示词，点击“填充到可灵（不生成）”。这一操作不要求可灵 CLI 登录；使用的是 Chrome 的可灵网页登录。
6. 插件复用打开的 `https://klingai.com/app/omni/` 标签页，没有则自动打开。填充成功后在画布显示结果；请在可灵核对模型、时长、分辨率等参数，需要生成时由用户点击网页“生成”。

插件不读取可灵凭据。后端队列和本地素材使用现有拾影登录会话鉴权并按账号隔离。浏览器权限仅覆盖 `localhost`、`127.0.0.1`、`klingai.com`。

## 行为与范围

- 支持 PNG/JPEG、MP4/MOV；当前仅接受画布中 `/assets/`、`/output/`、`/input/` 的本地素材。远程 URL、音频等会明确报错，不能静默丢弃。
- 支持中文“图片1 / 图1 / 视频1”、带 `@` 写法，以及画布可灵格式 `<<<image_1>>>` / `<<<video_1>>>`。引用不存在时停止填充。
- 同一插件刚填好的同一批素材，可以再次发送不同提示词而复用上传结果。人工改过当前草稿、参考素材改变或页面刷新后，需先保存并在网页点击“重置”；插件不覆盖未接管的草稿。
- 可灵当前简化编辑框会把正文换行折叠成空格，各段文字保留；素材标签本身在 DOM 文本中带换行。
- 一次只接收一份草稿，单文件上限 200 MB，最多 10 个文件；最终以可灵网页的模型限制为准，插件回传网页上传错误。
- 队列保存在内存，重启后失效，最多保留一小时；接收后五分钟没有回执标记失败，不自动重放上传操作。
- 这是网页填充通路，原 CLI 生成路径继续使用原逻辑。暂未实现从画布点击直接触发网页生成、网页生成进度和成片回收；本次用户要求只测试填充。
