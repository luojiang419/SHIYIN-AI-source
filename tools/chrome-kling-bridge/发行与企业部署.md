# 0.4.0 发行与企业部署

## 普通用户发行
1. 使用 Chrome Web Store 开发者账号提交扩展目录 ZIP；填写支持邮箱、隐私政策和商店截图。尚未上架，不能向用户承诺商店可安装。
2. 取得32位扩展ID后，在拾影后端启动环境配置 `SHIYIN_KLING_EXTENSION_ID`，重启后端。未配置时安装页明确提示管理员，不显示假安装按钮。
3. 普通用户首次点击画布生成，未连接10秒后出现引导；Chrome商店安装需用户确认。保留交接页，扩展安装事件会注入并续接原任务。
4. 扩展由商店更新。后端最低协议版本0.4.0，旧版传输领取会返回426。解压版升级仍需Chrome扩展管理刷新。
5. 修改代码后必须随正式热更新发布后端和前端，不能使用纯前端发布；本轮没有发布。

## Web 与浏览器配置
- 本机HTTP localhost/127.0.0.1自动配对，端口来自当前请求，无固定3000。
- 远程站点要求HTTPS；用户先在已安装扩展的弹窗输入站点地址，点击授权。扩展仅申请该站点主机权限并注册交接页脚本。HTTP局域网站点需部署HTTPS，当前不支持。
- 同一个Chrome用户配置中登录可灵并安装扩展。多个配置不能可靠自动判断哪一个已登录；界面指导用户使用正确配置，不读取其他配置Cookie。
- 任务凭据只放片段和当前标签sessionStorage，服务器状态接口不公开凭据；待连接15分钟过期，后端重启丢失任务后需重新发送。
- 刷新画布后点击生成会恢复queued/filling/submitting原任务；unknown不自动重发。已取消等待后不续接。

## 企业自动安装（管理员实施）
推荐将商店上架扩展ID加入现有Chrome `ExtensionSettings` 策略：

```json
{
  "替换为商店扩展ID": {
    "installation_mode": "force_installed",
    "update_url": "https://clients2.google.com/service/update2/crx"
  }
}
```

通过组织现有GPO、MDM或Chrome Enterprise管理台合并该条目，不覆盖已有扩展策略。该材料不会自动修改用户注册表、管理状态或安全策略。企业管理员授权后自行部署，撤销时只移除此扩展条目。

自托管CRX仅用于符合Chrome管理条件的设备；需要固定签名密钥、稳定扩展ID、HTTPS更新清单及CRX托管。当前未实现自托管签名发布，局域网分发中心未改动。

## 隐私说明草案（发布前补全经营主体和联系方式）
插件接收用户在拾影画布主动提交的图片、视频、提示词和生成参数，并上传至用户已登录的可灵页面进行生成。插件在本机保存服务器地址、短期队列连接凭据、待处理任务和状态；不读取可灵Cookie、密码或其他浏览历史，不附加统计服务。远程拾影站点仅在用户主动授权后访问。生成素材的保存与删除遵循拾影和可灵各自政策。用户可停止接收、撤销站点权限或卸载扩展。
