## 安装与升级

运行安装包并完成 Windows 管理员授权。默认安装到 `D:\Program Files\SHIYIN-Depth-Batch`，从开始菜单或桌面快捷方式启动。

**已安装 1.0.1–1.0.3 的用户，请先关闭软件，使用 1.0.4 安装包覆盖安装。** 这些旧版本的更新器存在脚本故障，可能无法通过旧程序内的更新按钮完成修复。旧安装包及旧更新包已从当前下载目录撤下；覆盖安装无需删除已下载的运行时和模型。

1.0.4 修复管理员更新脚本执行失败（退出码 1），兼容中文、空格与特殊路径。启动时自动检查一次更新，在主窗口中央显示更新弹窗；确认后由独立更新器完成替换并自动重新启动软件。安装版与签名更新基线一致，新装后不会重复提示同一版本。

## 使用

1. 导入多个视频，选择输出目录、Base / Small 模型及提取模式。人物模式分割人物并保持背景纯黑；专业模式输出整幅画面的深度。
2. 点击“开始批量提取”。首次使用自动下载运行时与模型并校验 SHA-256，请预留至少 25 GB 空间。下载失败可重试续传，组件准备期间可取消；日志位于 `runtime/component-install.log`。
3. 视频按顺序处理并保留原始帧率、全部帧和分辨率。暂停在当前视频结束后生效；单项失败不阻断后续任务。
4. 每项输出位于独立时间戳目录，包括 `原文件名_depth.mp4`、原始深度数据和元数据。支持播放定位、独立全屏与双击划像对比。调整参数后可导出到该任务的 `adjusted` 目录。
5. 队列与参数保存在本机；未完成视频重新启动后从头处理。单个推理进程结束会回收其 CUDA 显存，播放与窗口可能仍占用少量图形显存。

安装包不包含 Python / PyTorch / CUDA / FFmpeg 运行时及模型，首次下载后可离线使用，无需手动安装 Python。Windows 需具备 Microsoft Edge WebView2 Runtime。`worker-overlays` 用于兼容公开运行时，请勿删除。
