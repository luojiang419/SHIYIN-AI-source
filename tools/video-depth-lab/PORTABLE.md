# SHIYIN 批量深度视频提取器

Windows 10/11 x64 安装版。运行 `SHIYIN-Depth-Batch-Setup-1.0.0.exe` 完成安装后，从开始菜单或桌面快捷方式启动。软件会在设置中检查签名更新；更新由独立更新进程完成，无需手动下载新安装包。

1. 导入多个视频，选择输出目录、Base / Small 模型和提取模式。“人物模式”会自动分割人物并保持背景纯黑；“专业模式”输出整幅画面的全部深度。
2. 点击“开始批量提取”。首次使用会从魔塔下载对应 CPU / CUDA 运行时和模型，并检查 SHA-256；运行时较大，请保留至少 25 GB 可用空间。下载失败后重新点击可续传。
   下载期间显示已下载大小与等待时间，可点击“取消准备”；校验、合并和解压期间显示当前阶段。准备日志保存在 `runtime/component-install.log`。
3. 视频按顺序处理，保留原始 FPS、全部帧和分辨率。暂停在当前视频完成后生效；失败项不阻断后续任务，点击开始可重试。
4. 每项输出位于独立时间戳目录，包含 `原文件名_depth.mp4`、原始深度数据和元数据。输出位置面板右下角可打开输出目录。选中已完成任务可播放，拖动进度条定位，点击全屏按钮独立全屏播放；双击画面进入划像对比，支持同步进度定位。调参后点击“应用参数并导出调整版”，文件保存至该任务的 `adjusted/原文件名_depth.mp4`。界面滤镜为近似预览，导出按原始深度精确计算。
5. 队列与参数保存在本机，关闭时未完成的视频下次从头重试，不提供视频内部断点推理。
6. 程序使用单实例锁：重复启动会唤起已有窗口。每个视频推理进程退出后回收其 CUDA 显存；全部提取完成或队列暂停时会显示“显存已释放”。异常返回也会回收本工具的推理进程。视频播放与窗口自身的图形显存仍可能占用少量资源。

安装包不包含 Python / PyTorch / CUDA / FFmpeg 运行时与模型权重。下载完成后可离线使用，无需自行安装 Python。Windows 需具备 Microsoft Edge WebView2 Runtime。

人物模式首次额外下载约 6 MB 的 OpenCV 人物分割模型。Small 使用 Apache-2.0；Base 使用 CC-BY-NC-4.0，仅限非商业用途。运行时与模型许可证沿用上游项目。

`worker-overlays` 为与三种公开运行时逐一匹配的入口程序更新，仅更新本工具自有 worker 模块；保留对应运行时第三方模块，补齐 Small 注册和批量功能。请勿删除。
