# 电商专用平台标准 API 配置页改造 - 功能开发文档

## 任务目标

将 API 设置中的“电商专用”平台从仅展示视觉模型的专用表单，改为与普通 OpenAI 兼容平台一致的标准配置页：支持请求地址、API Key、协议、图片/聊天/视频模型列表及模型拉取等常规配置，同时保留电商页面使用聊天视觉模型进行商品解析的能力。

## 验收标准

1. 在 API 设置选择“电商专用”时，页面显示与普通平台相同的请求地址、API Key、协议选择和三类模型列表；不再只显示一个“视觉模型”列表。
2. 可以新增、删除、编辑电商平台的图片/聊天/视频模型并保存，刷新后数据仍在。
3. 电商页面的商品/模特/场景解析继续从电商平台的聊天模型中选择视觉模型，不因页面改造失效。
4. 现有本地视觉模型仍保持专用视觉配置行为，其他平台行为不回归。
