# 画笔增强与移除灯光重塑节点 - 功能开发文档

## 任务目标

1. 在编辑图片的“画笔”页面增加可弯曲箭头工具，支持拖拽绘制带箭头的曲线，并通过拖拽轨迹调整弧度。
2. 在画笔颜色控件旁增加红、黄、绿、蓝、黑、白常用色预设，点击即可切换颜色。
3. 修复作品管理页面生成图片缩略图因资源地址未经过后端代理而显示损坏图标的问题。
4. 从画布和智能画布中移除“灯光重塑”节点、菜单、快捷键及相关渲染/生成逻辑。

## 验收标准

- 画笔工具栏出现“弯曲箭头”，拖拽轨迹可得到方向明确、带箭头头部的曲线；箭头与其他绘制内容可撤销/重做并随图片导出。
- 颜色预设包含红黄绿蓝黑白，点击后颜色输入值立即同步。
- 作品管理中灯光重塑生成的图片正常显示，远程和本地资源均可预览。
- 新建节点菜单、快捷键、节点渲染、连线和生成逻辑中不再出现灯光重塑入口；历史数据中的旧节点不会阻塞页面加载。
