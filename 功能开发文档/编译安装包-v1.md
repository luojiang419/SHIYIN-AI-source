# 编译安装包功能开发文档 v1

## 任务目标

基于当前源码版本编译 Windows 桌面安装包，完成构建产物、运行时冒烟检查和安装包存在性校验，交付可安装的对应版本安装包。

## 拆分步骤

1. 检查最新进度快照、版本同步状态、构建脚本和运行中的桌面实例。
2. 关闭占用构建资源的 SHIYIN AI 实例，执行完整安装包构建流程（后端、Tauri 桌面端、打包暂存目录、运行时 smoke、Inno Setup）。
3. 校验安装包文件、大小、版本命名和构建日志；必要时记录构建问题与解决方案。
4. 更新开发进度、生成进度快照，并保留可追溯的构建产物记录。

## 文件/模块清单

- `tools/build-installer.ps1`：安装包完整构建入口。
- `installer/shiyin_ai.iss`：Inno Setup 安装包定义。
- `VERSION`、`package.json`、`src-tauri/tauri.conf.json`：版本同步来源。
- `dist/installer/`：最终安装包输出目录。
- `功能开发文档/`、`进度快照/`、`避坑指南/`：过程记录。
