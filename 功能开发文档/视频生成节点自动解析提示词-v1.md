# 视频生成节点自动解析提示词功能开发文档 v1

## 任务目标

当视频生成节点只连接图片、且节点内没有提示词、上游没有提示词/链接提示词节点时，将操作按钮显示为“自动解析”。点击后将全部图片按真实连接顺序放入同一个多模态 API 请求，结合优秀案例经验和当前视频模型 skill，生成包含分镜、景别/角度、运镜、动作时序、节奏与必要声音的规范化视频提示词，并回填节点提示词输入框；已有提示词时则在同一个请求中组合“图片 + 用户提示词 + skill”进行润色。

## 拆分步骤

1. 梳理普通 `video` 与影视 `film-video` 节点的提示词、图片顺序、模型选择和润色调用链路。
2. 扩展后端自动解析请求：支持无初始提示词、按顺序将全部图片放入同一个请求、案例经验上下文、按视频模型 skill 规范化输出；有提示词时组合图片与用户提示词共同请求。
3. 扩展前端按钮状态：仅图片条件显示“自动解析”，有节点内或上游提示词显示“润色”；经典/智能画布共用逻辑。
4. 接入自动解析流程：先视觉分析，再基于分析结果生成最终提示词，成功后回填并持久化；失败时恢复按钮状态并保留错误提示。
5. 增加回归测试（后端请求模型、前端条件与顺序契约、语法检查），更新版本、快照、备份与避坑记录。

## 文件/模块清单

- `main.py`：自动解析请求模型、视觉分析与提示词生成 API、视频模型 skill/案例上下文拼接。
- `static/js/canvas.js`：普通视频节点按钮状态与自动解析调用。
- `static/js/canvas-film-nodes.js`：影视生成视频节点按钮状态与自动解析调用。
- `static/js/smart-canvas.js`：智能画布节点提示词/图片顺序、调用适配与持久化。
- `tests/`：自动解析接口与前端静态契约测试。
- `功能开发文档/`、`进度快照/`、`backup/`、`避坑指南/`：过程记录与溯源。

## 验收标准

1. 仅连接 1 张或多张图片、无节点内提示词、无上游提示词时，按钮文案为“自动解析”。
2. 连接图片顺序保持不变，视觉模型收到的图片与编号严格一致，不因去重或并发重排。
3. 自动解析在同一个多模态请求中完成联合画面分析、案例经验吸取和当前视频模型 skill 输出；结果包含可执行的分镜/镜头、景别或角度、运镜、动作先后与节奏信息。
4. 生成结果仅回填最终规范化提示词，不回填分析过程；失败不覆盖原内容并给出可见错误。
5. 只要存在节点内提示词或上游提示词/提示词节点，按钮文案保持“润色”，原有润色行为不回归。
6. 普通与智能画布、`video` 与 `film-video` 节点均通过静态契约、Python 测试和 JavaScript 语法检查。
