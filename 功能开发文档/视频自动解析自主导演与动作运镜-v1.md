## 任务目标

无文字提示词时，依据全部参考图识别可连续延展的动作和主体关系，以导演思维自动编排开场、发展、变化和收束；自动规划主体表情/视线/身体动作、动物或拟动物行为、物体反应、环境反馈和有叙事目的的自然运镜。有文字提示词时，保留用户原意并仅补足可执行细节。

## 技术方案

- 参考图作为外观、身份、空间和材质事实；用户提示词作为不可覆盖的故事主线。
- 每个镜头拆成主动作、细微反应、二级环境运动、物理反馈、镜头关系和声音节拍。
- 多主体使用错峰和波纹式反应，避免同步机械动作；状态变化必须可见。
- 用户未指定固定机位时，默认选择跟随、推进、拉远、横移、环绕、升降、摇摄或前景穿越等有目的的运镜，并说明方向、速度和揭示目标。
- 每个镜头只保留一个主动作和一个主导运镜；复杂变化以时间分段或受控多镜头表达。
- 输出经过模型标签归一化后，确定性检查所有图片标签是否出现；缺失时拒绝静默交付。

## 验收标准

1. 无提示词 + 多张参考图时，输出有时间推进、动作差异、主体反应、物理反馈和非固定运镜。
2. 有提示词时，明确主体、故事、动作、情绪和否定要求不被改变，只新增合理的可见细节。
3. 动物/拟动物或拟人化物体不会全部同步重复同一动作；至少有主次、错峰或观察关系。
4. 四图输入最终提示词缺少任何规范图片标签时，接口返回明确错误，不交付不完整结果。
5. H3/Kling 现有 skill 字段、标签、自然编号归一化和既有测试不回归。

## 外部经验摘要

- Runway 官方：图片负责外观事实，文本聚焦具体运动；多主体用明确位置/身份；避免抽象概念和过度复杂动作。
- Runway Camera Guide：景别 + 角度 + 方向/速度/运动 + 主体动作 + 镜头观感 + 光线 + 画面揭示，并明确镜头与主体的关系。
- Seedance 实践：Subject → Action → Camera → Setting/Lighting → Style → Audio；单镜头单主动作，复杂动作拆节拍。
- 社区 Shot List：主体/环境/风格与逐镜头角度、焦段、运动、动作、SFX 分层，显式镜头语言和音效有助于连续性与重量感。
