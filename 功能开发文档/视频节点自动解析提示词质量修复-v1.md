# 视频节点自动解析提示词质量修复 v1

## 任务目标

修复视频节点“自动解析”结果中出现与画面无关的散装质量词（如 `Photorealistic, 8k resolution.`）以及偏离官方视频提示词案例结构的问题。没有任何文字提示词时，由 GPT-5.6 Sol 进入自主导演模式，从图片事实出发设计精彩、完整且可执行的时间推进，并严格按所选视频模型 skill 输出。案例只用于迁移镜头组织方法，不得复制案例主体、场景或泛化画质尾缀。

## 拆分步骤

1. 定位自动解析后端系统提示词、单次多模态请求和结果归一化链路。
2. 增强模型约束：明确禁止质量标签堆砌、禁止复制案例内容，并要求输出与所选 skill 的结构一致。
3. 修复自动解析未真正注入所选视频模型 skill 正文的问题；无文字提示词时启用自主导演模式，要求完整短时叙事与镜头节奏。
4. 增加确定性后处理：清理常见泛化质量尾缀/独立质量短语，压缩重复空白，避免污染用户提示词。
5. 增加回归测试，覆盖 skill 正文注入、自动解析和普通润色两条路径，验证引用标签仍保留。
6. 更新版本、开发进度、快照、备份和避坑记录，并执行全局测试。

## 验收标准

1. 自动解析结果不再以 `Photorealistic`、`8k resolution` 等泛化质量标签收尾或单独成句。
2. 清洗不删除主体、动作、镜头、时序、对白或合法 skill 引用标签。
3. 解析系统提示词明确“案例仅迁移方法，不复制内容”，并要求素材事实优先。
4. 无提示词时不是静态图片复述，而是包含开场、发展、转折/揭示与收束的可执行视频叙事。
5. Kling 自动解析真实注入 Kling skill；MiniMax H3 自动解析真实注入 H3 主 skill 与 references 完整正文。
6. 自动解析和已有提示词润色均通过回归测试，引用标签映射保持稳定。
