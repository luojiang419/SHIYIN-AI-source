# 画布平移媒体节点空白修复

状态：已完成
当前阶段：3/3
最后更新：2026-09-01

## 当前状态

用户反馈进入画布后平移画布，图片/视频节点内容突然变为空；退出画布再进入后恢复。已确认经典/智能画布在大画布场景中对节点视觉子树使用 `content-visibility:auto`，而平移时持续变换 `.world`，该组合可能导致浏览器跳过视觉子树绘制，表现为节点空白。现已在平移期间关闭该 paint containment，并覆盖小地图拖动路径。

## 下一步

当前任务已完成。若现场仍出现空白，下一步应采集浏览器现场的 DOM/CSS 计算样式与 Network/Console 信息，确认是否存在媒体文件自身不可访问。

## 任务目标

平移或缩放画布时，已有图片/视频节点始终保持可绘制，不因 LOD 的 `content-visibility` 与世界变换组合变成空节点；不改变节点数据、媒体 URL 和持久化格式。

## 技术方案

- 在经典画布 CSS 中增加 `body.canvas-board-pan` 期间的视觉壳绘制保护，覆盖大场景 LOD 的 `content-visibility:auto` 和 contain。
- 在智能画布 CSS 中增加 `.shell.panning` 期间的节点 body 绘制保护，覆盖智能 LOD 规则。
- 保留平移结束后的既有 LOD 重算，以继续获得静止状态的性能收益。
- 增加测试断言，确保平移保护存在且 LOD 基础规则仍保留。
