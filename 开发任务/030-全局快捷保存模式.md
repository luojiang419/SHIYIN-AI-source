## 任务目标

在“设置 → 软件设置”增加“快捷保存”设置项：

- 手动保存：保持当前下载行为，由系统或浏览器显示保存窗口。
- 静默保存：显示目录选择控件，选择后所有主要功能页面的下载操作直接保存到该目录，不再弹出保存窗口。
- 静默保存仅允许本机管理员使用，避免局域网账号触发主机文件写入。

## 当前项目现状

- 软件设置持久化位于 `canvas_core/app_config.py`，保存到 `data/config/app.json`。
- 设置接口与 Windows 原生目录选择位于 `main.py` 的 `/api/app-settings` 路由组。
- 单文件媒体下载通常通过 `/api/download-output`，批量下载通常先生成 Blob 再触发带 `download` 属性的链接。
- 经典画布输出节点另有 `showDirectoryPicker` / Tauri 桥接的批量逐文件保存流程。
- 设置页位于 `static/app-settings.html`、`static/js/app-settings.js`、`static/css/app-settings.css`。
- 各业务页面使用多个独立下载 helper，不能只修改单个画布文件。

## 技术方案

- 配置新增 `quick_save_mode`（`manual` / `silent`）与 `quick_save_dir`。
- 保存静默模式时校验目录为可写绝对路径；未选择目录时拒绝启用。
- 提供只返回快捷保存状态的本机接口，以及可接收 URL 或浏览器 Blob 的静默写盘接口。
- URL 下载采用流式复制，避免大视频整体载入内存；文件重名时自动追加序号，不覆盖已有文件。
- 新增公共 `quick-save.js`，在捕获阶段拦截带 `download` 属性的链接及明确的下载路由；手动模式完全放行。
- Blob / data URL 由浏览器读取后上传；普通媒体 URL 交给后端流式保存。
- 通过 BroadcastChannel 同步设置变更，已打开页面无需刷新即可切换模式。
- 经典画布的批量目录保存函数显式查询公共快捷保存状态，在静默模式逐文件写入配置目录。

## 验收标准

- 默认与旧配置均使用手动保存，当前下载流程不变。
- 设置为静默保存但未选择目录时不能保存无效配置。
- 设置页仅在静默模式显示目录控件，并可选择、更换目录。
- 单文件、远程媒体、Blob/ZIP 与经典画布批量输出都可静默写入目标目录。
- 同名文件不会覆盖，自动生成唯一文件名。
- 普通局域网账号无法读取目录或调用静默写盘接口。
- 静默保存成功或失败具有可见反馈。
