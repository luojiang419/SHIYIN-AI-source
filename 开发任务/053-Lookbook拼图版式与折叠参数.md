## 任务目标

1. Lookbook 节点的生成参数改为默认折叠项，并在折叠标题显示关键参数摘要。
2. 增加拼图版式按钮和弹窗，以缩略图展示常用布局。
3. 弹窗支持自定义行数、列数和图片间距，最多 20 个子画面。
4. 子画面比例继承节点当前画幅；布局参数进入图片 API 提示词。
5. 单排、单列等无法严格匹配的布局使用 API 支持的最近输出比例，不增加本地拼接。
6. 用户明确选择的版式优先于文案自动识别；选择自动时保留现有自然语言识别行为。

## 当前项目现状

- `static/js/canvas-lookbook-node.js` 负责节点 UI、状态归一化、风格弹窗和参数事件。
- `static/js/canvas.js` 负责请求组装、任务轮询、状态恢复和输出节点。
- `canvas_core/lookbook_story.py` 已能从自然语言识别明确拼图意图，但没有结构化行列和间距。
- `main.py` 当前会用文案解析结果覆盖前端传入的 `lookbook_layout_intent`。
- `build_lookbook_shot_prompt` 当前会重新解析原始文案，不能直接执行前端结构化选择。
- 现有图片 API 没有独立 gutter 参数，间距只能通过提示词做近似控制。

## 技术方案

- 节点持久化 `lookbookLayoutSelection`，包含 `preset_id`、`rows`、`columns`、`gap`。
- `lookbookLayoutIntent` 继续作为后端派生状态，不与用户选择混用。
- 后端白名单归一化布局选择，限制行列为 1～5、总格数为 1～20、间距为 0～3。
- 最终画布目标比例按 `子画面比例 x 列数 / 行数` 推导，再映射到 API 支持的最近比例。
- 结构化选择优先级：用户弹窗选择 > 文案明确要求 > 默认单幅。
- 提示词明确写入行列、总格数、阅读顺序、子画面比例、间距等级、零外边距和禁止装裱外框。
- `auto` 保留文案自动识别；`single-frame` 明确关闭拼图。

## 验收标准

- 新建和旧 Lookbook 节点默认折叠生成参数，用户可展开并正常修改。
- 节点显示“拼图版式”按钮和当前选择摘要。
- 弹窗包含自动、独立成片、单排三张、单列三张、四宫格、九宫格缩略图。
- 行数、列数可调整且总格数不超过 20；预览随设置实时更新。
- 间距滑杆至少支持无、窄、标准、宽四档，并进入最终提示词。
- 子画面比例使用节点当前画幅，单排/单列按 API 支持画幅适配。
- 提示词严格禁止外框、底板、阴影和悬浮纸张。
- 修改需求文案不会清除用户明确选择的版式。
- 旧节点和仅靠自然语言声明拼图的任务继续兼容。
