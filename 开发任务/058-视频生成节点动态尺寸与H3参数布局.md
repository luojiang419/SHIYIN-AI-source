## 任务目标

经典画布“视频生成”节点必须在任何允许的缩放状态下完整显示单排六个输入媒体缩略图、全部生成参数和生成按钮；第七个及后续媒体自动换行，节点高度随行数增长。节点宽度不得无限缩小或拉长。影视“生成视频”节点的 MiniMax H3 参数面板复用经典视频节点的规范化网格布局。

## 当前项目现状

- `static/css/canvas.css` 已使用 `repeat(6,minmax(0,1fr))`，但通用节点最小宽度仍为 220px。
- `static/js/canvas.js` 的通用缩放逻辑会同时保存 `node.w` 和 `node.h`，最大宽高没有限制。
- 视频节点默认宽度为 400px，已有保存数据可能包含过窄、过宽或过低的尺寸。
- `static/js/canvas-film-nodes.js` 的 H3 面板使用多层 `.gen-settings-row`，`static/css/canvas-film-nodes.css` 又对外层设置四列网格并对 H3 单独改为 flex，布局规则交叉。
- 影视节点模块同时服务经典画布和智能画布，样式调整必须同时兼容两处。

## 技术方案

1. 为经典视频节点定义明确的最小/默认/最大宽度，渲染前归一化历史尺寸并删除固定高度。
2. 视频节点缩放改为仅调整受限宽度；高度由自然内容流决定。这样媒体每六个形成一排，第七个开始新增一排时节点自然增高，参数区和按钮不会被挤入滚动容器。
3. 六列媒体网格显式固定横向、纵向间距，缩略图使用稳定的正方形比例。
4. H3 参数面板采用平台/模型行、三列主参数网格、两列辅助参数网格和独立模式开关行；复用 `.gen-settings-row`、`.field`、`.setting-title`、`.setting-input`、`.select-lite`、`.setting-check` 控件语言，并在影视模块补齐不依赖经典画布 CSS 的共享样式。
5. 增加静态契约测试覆盖尺寸归一化、缩放上下限、自动高度、多排间距及 H3 网格结构；使用浏览器截图验证一排与两排场景。

## 验收标准

1. 视频节点缩到最小时，六个缩略图仍完整、清晰地显示在同一排。
2. 第七个媒体开始第二排，继续缩放节点时第二排完整显示，无裁切、内部滚动或覆盖参数区。
3. 参数区、提示词区和生成按钮始终完整显示。
4. 视频节点宽度只能在规定范围内调整，不能无限拉长；高度始终随内容自动适配。
5. 多排缩略图行列间距固定，编号、帧角色、预览和拖拽排序行为不变。
6. 影视“生成视频”的 H3 参数按清晰网格显示，在经典和智能画布中均不混乱。
7. 相关 JS 语法检查、定向测试和视觉回归通过。
