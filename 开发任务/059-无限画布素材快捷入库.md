## 任务目标

让用户在当前统一无限画布内把外部图片、视频或音频直接拖入当前选定的任意素材库分组；素材卡片底部名称可双击原位编辑；所有包含有效图片或视频的媒体节点顶部菜单提供“添加为素材”，点击后可以选择目标素材库、素材分组并确认名称。

## 当前项目现状

- `main.py` 已提供 `/api/asset-library/items/upload`、`/api/asset-library/items` 和素材 PATCH 接口。
- `static/js/canvas.js` 已能读取素材库并向当前分组保存。
- 外部拖放只绑定独立 drop zone，素材卡双击默认添加到画布。
- `smart-canvas.html` 是退役兼容页，加载时立即跳转到 `canvas.html`，不应继续新增重复实现。

## 技术方案

- 在 `canvas.html` 增加原生素材保存弹窗，由 `canvas.js` 加载素材库、过滤可保存媒体的普通分组并提交现有素材新增 API。
- 保存成功后更新画布内存中的素材库；不新增后端数据结构和接口。
- 素材侧栏外部拖放使用明确的目标库/分组参数，避免异步解析拖放内容期间下拉选择变化导致保存错组。
- 卡片名称双击时阻止卡片默认双击行为，复用现有 PATCH 接口执行原位编辑。
- 菜单入口仅对有有效 URL 的图片/视频素材启用。

## 验收标准

- 无限画布素材侧栏打开后，外部支持格式文件可保存到当前选定素材库与分组。
- 拖放开始时的目标分组在异步解析期间保持稳定，不因 UI 状态变化保存错组。
- 普通素材卡底部名称双击后出现原位输入框；Enter/失焦保存，Escape 取消。
- 图片和视频媒体节点顶部菜单均显示“添加为素材”。
- 点击后弹窗可选择任意非本地素材库及其媒体分组、编辑素材名称并成功保存。
- 保存成功后当前画布素材库数据同步刷新；无分组、接口失败等错误有明确反馈。
- `node --check`、相关 pytest 与 `git diff --check` 通过。
