## 任务目标

1. 在生成图片节点双击打开的全屏预览中，在下载按钮左侧增加复制图标，将当前原图复制到系统剪贴板。
2. 以“生成视频”节点的固定框架和最小尺寸策略为基准，规范统一画布全部节点布局。
3. 保证按钮、缩略图、提示词和生成参数在允许的最小尺寸内不被遮挡、压扁或异常拉伸。
4. 不改动节点生成、连线、参数含义、任务恢复等业务行为。

## 当前项目现状

- 统一画布节点经过 `renderNode()` 和 `defaultNodeSize()`，原缩放下限把多数节点放宽到 220×96，容易挤压参数区。
- “视频生成”节点已有 440–520px 宽度约束与内容驱动高度，是本任务的行为基准。
- 图片/视频缩略图已有 `object-fit: cover/contain` 比例策略，本任务保留该策略。
- 旧智能画布入口已下线并重定向到统一画布。

## 技术方案

1. 新增同源图片读取与 PNG 转换函数，使用 `navigator.clipboard.write()` 和 `ClipboardItem` 写入系统剪贴板；按钮仅在图片预览时显示。
2. 建立统一节点类型最小尺寸规范，渲染和缩放处理共同读取；参数型功能节点至少采用 440px 基准宽度，大型节点保留自身更大下限。
3. 默认高度为自动的功能节点使用内容驱动高度并只允许横向缩放；Prompt、Loop、图片、分组和固定舞台节点保留原有纵向缩放语义。
4. 用通用框架 CSS 约束节点标题、正文、操作区、表单网格和媒体容器，避免子项撑破或被强制拉伸。
5. 纠正影视节点尺寸提供器对非影视类型返回 520px 的串扰。
6. 增加静态契约测试，并在统一画布构造多类型节点进行截图、尺寸和系统剪贴板验证。

## 验收标准

1. 统一画布生成图片的全屏预览显示复制图标，且位于下载按钮左侧。
2. 点击复制后系统剪贴板获得当前预览图片；JPEG/WebP 等输入统一以 PNG 写入。
3. 视频预览不显示复制图片按钮，不影响原下载与视频工具。
4. 所有功能节点不能缩小到低于各自内容所需的规范尺寸，历史过小尺寸会在渲染时修正。
5. 内容驱动节点高度随缩略图、参数和状态内容自然增长；固定舞台节点在最小尺寸下仍可访问全部控件。
6. 缩略图保持比例，参数网格不横向溢出，按钮文字和图标不互相遮挡。
7. 节点生成、连线、运行、删除、下载与参数保存逻辑不变。
