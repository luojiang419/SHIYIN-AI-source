## 任务目标

深度图节点内“输入图片”区域支持直接点击或键盘操作选择图片；手动图片支持替换和移除，同时保留输入端口连线能力。只要存在手动图片，深度推理必须忽略连线图片；用户移除手动图片后，节点自动回退到当前连线输入并重新生成深度图。

## 当前项目现状

- 经典画布 `depthMap` 与智能画布 `depth-map` 共用 `static/js/canvas-special-nodes.js`。
- `depthMapManualInput` 已随节点对象持久化，工具栏与智能画布拖放可写入该字段。
- `depthMapInput` 当前先读取 `options.getInputImage(node)`，导致存在连线时手动上传不生效。
- 输入预览卡只是普通 `div`，没有上传交互、来源标识或移除按钮。
- 输入签名变化会清空旧结果并重新推理，可直接复用来完成优先级切换。

## 技术方案

- `depthMapInput` 先返回有效 `depthMapManualInput`，没有手动图片时再读取画布连线。
- 输入预览卡增加 button 语义、键盘 Enter/Space 支持、手动/连线来源标识和手动图片移除按钮。
- 点击输入卡或原工具栏按钮共用现有隐藏 file input 与上传逻辑。
- 上传后同步输入签名、清理旧深度结果并从手动图片重新推理。
- 移除后删除 `depthMapManualInput`，重新解析连线输入；存在连线时立即重新推理，不存在时回到等待输入状态。
- 不删除画布连接，确保手动图片存在期间只是逻辑忽略，移除后能无损恢复。

## 验收标准

1. 点击节点内“输入图片”区域会打开图片选择器，空状态和已有图片状态均可操作。
2. 手动上传后显示手动来源与移除按钮，并基于手动图片生成深度图。
3. 手动图片存在时，新建或更换输入连线不会改变当前深度推理输入。
4. 移除手动图片后，若有有效连线则自动显示并处理连线图片；若无连线则清空旧结果并回到等待状态。
5. 原工具栏导入、拖放导入、高级控制、输出同步和工程持久化保持可用。
6. 经典与智能画布静态检查、专项测试和必要回归测试通过。
