服装参考格支持一次多选、继续追加、最多 20 张、缩略图预览和逐张删除。旧画布保存的单对象服装输入会自动规范化为数组。手动集合存在时覆盖连线输入；移除最后一张后恢复连线。连接 Group/Output 时也能读取其中的多张图片。

## 任务目标

一键复刻节点第一输入改称“目标图片”，它是需要生成深度图/骨架图并承载目标姿势的人物图片；第二输入改称“服装参考”，它是需要换到目标图片人物身上的服装来源。服装参考允许一次上传多张色号或款号图，并以同一个目标姿势并发生成一张对应结果。

## 当前项目现状

- 共享节点实现位于 `static/js/canvas-special-nodes.js`，经典与智能画布复用。
- 经典画布提交位于 `static/js/canvas.js`，当前每次调用创建一个 pending 和一项 `/api/canvas/pose-replicate-tasks`。
- 智能画布提交位于 `static/js/smart-canvas.js`，当前每次创建一个单槽 Output。
- 服务端 `PoseReplicateInputs` 保持每项任务一张 `target_image`；适合由前端拆为多项并发任务，无需引入破坏性 API 变更。
- 提示词唯一来源为 `canvas_core/pose_replicate_prompts.py`，当前模板版本 `pose-replicate.v2.5`。

## 技术方案

- 保留 `pose-reference`、`target-image`、`pose_reference`、`target_image` 内部字段，避免旧画布迁移和 API 兼容风险；只更新面向用户与模型的角色命名。
- `poseReplicateManualInputs['target-image']` 兼容旧对象并规范化为数组；其他角色仍为单对象。
- 服装参考卡使用多选文件输入，追加上传，最多保留 20 张；缩略图提供逐张删除，手动集合存在时继续覆盖连线输入。
- 点击“一键复刻”时只调用一次批量生成入口；经典/智能画布按服装数组建立等量槽位，并发提交独立任务。每项请求只携带对应服装参考，保证提示词图号和角色所有权不混淆。
- 模板升级为 `pose-replicate.v2.5`，统一使用“目标图片 / 服装参考”，并明确“一项任务只使用当前服装参考，不得混入同批其他款式”。

## 验收标准

- 节点卡片、输入端口、状态和错误提示不再把第一格称为“动作参考”、第二格称为“目标图”。
