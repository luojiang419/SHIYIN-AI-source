## 任务目标

在 Windows 桌面软件获得焦点时，用户按下 F11 可进入全屏，再次按下 F11 可退出全屏，使标题栏和系统窗口边框不占用创作空间。

## 当前项目现状

- 桌面端使用 Tauri `2.11.5`
- 主窗口由 `WebviewWindowBuilder` 动态创建
- 软件包含多个 HTML 页面并在同一主窗口内导航
- 页面中存在媒体预览级全屏功能，但没有整个软件窗口级快捷键
- 当前工作区包含其他任务的未提交修改，本任务必须精确隔离提交

## 技术方案

1. 接入 `tauri-plugin-global-shortcut 2.3.2`，使用无修饰键 `Code::F11`。
2. 主窗口创建后立即注册 F11，`WindowEvent::Focused` 负责失焦注销与重新聚焦注册，避免占用其他软件的 F11。
3. 热键回调只处理 `ShortcutState::Pressed`；Windows 使用 `GetForegroundWindow()` 与主窗口 `HWND` 比较，其他平台回退 `is_focused()`。
4. 读取 `is_fullscreen()` 后调用 `set_fullscreen(!current)`，同一路径完成进入与退出。
5. 单元测试覆盖 F11、释放事件、非前台状态和其他功能键，隔离桌面测试覆盖真实 Windows 窗口边界和样式变化。

## 验收标准

1. 桌面软件任意页面按一次 F11 后，主窗口进入全屏。
2. 再按一次 F11 后，主窗口恢复非全屏状态。
3. 输入框、文本域等控件获得焦点时快捷键仍有效。
4. 长按 F11 不因键盘自动重复而快速来回切换。
5. 浏览器访问模式不受影响。
6. Rust 单元测试、格式检查和差异检查通过。
