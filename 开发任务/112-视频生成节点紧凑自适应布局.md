## 任务目标

经典画布“视频生成”节点在未运行及少量输入时按实际内容紧凑显示，不再固定拉长；连接图片/视频/音频缩略图区始终保持稳定尺寸，不因节点布局收缩；单排最多 6 个输入，第 7 个起自动换行并保持一致间距。

## 当前项目现状

- `static/js/canvas.js` 定义 `CLASSIC_VIDEO_NODE_MIN_HEIGHT = 700`，默认尺寸和历史尺寸归一化都会保留至少 700px。
- `static/css/canvas.css` 对 `.video-node` 设置 `min-height:700px`，固定框架中的 `.generator-canvas-content` 会占据剩余空间。
- `.video-img-list` 已使用六列 CSS Grid 和 `8px / 12px` 行列间距。
- 视频长提示词当前固定在 textarea 内滚动，不再依赖节点整体固定高度。

## 技术方案

1. 视频节点默认高度改回 `0`，布局归一化将视频节点识别为自动高度并删除历史 `node.h`。
2. 视频节点只允许在 `440–520px` 范围内横向调整，垂直尺寸始终由内容流决定。
3. 视频媒体内容区和缩略图网格设为不可收缩、无内部高度拉伸；缩略图维持六列正方形单元，第 7 个及后续输入自然新增网格行。
4. 底部参数、提示词和生成按钮保持普通文档流，长提示词继续在编辑框内部滚动，避免遮挡或越界。
5. 通过浏览器几何测量验证不同输入数量的行数、高度、间距、缩略图边长和底部边界。

## 验收标准

1. 3 个输入的未运行视频节点不再强制达到 700px，媒体区下方无无意义空白。
2. 1–6 个连接缩略图保持同一排；第 7 个开始第二排，12 个输入形成两排。
3. 缩略图为稳定正方形，各行列间距一致，不因节点高度或长提示词收缩。
4. 节点高度随输入行数自然增长，媒体区、参数区、提示词区和生成按钮互不覆盖。
5. 历史画布保存的 320px、700px 或更高视频节点高度打开后统一迁移为内容驱动高度。
6. 相关 JS 语法、Python 定向测试和隔离 Playwright 布局验证通过。
