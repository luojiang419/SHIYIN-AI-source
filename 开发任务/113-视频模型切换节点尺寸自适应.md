## 任务目标

普通“视频生成”和影视“生成视频”节点在可灵 CLI、MiniMax H3、LinkFox 间切换时，节点尺寸必须立即跟随当前完整内容收放；不得保留上一模型参数区造成的空白，不得裁切、折叠或遮挡缩略图区、资产映射、提示词、参数和底部动作区，也不得允许无边界手动拉伸破坏节点框架。

## 当前项目现状

- 经典普通视频节点已使用 `440–520px` 宽度和内容驱动高度，长提示词在 textarea 内滚动。
- 经典影视 `film-video` 默认尺寸为 `520×auto`，但影视提示词仍调用 `fitAutoTextNode` 写入 `node.h`。
- 智能画布 `imageLayout()` 对 `film-video` 固定返回至少 `430px` 高，并继续读取历史 `node.h`。
- 智能画布所有 `film-video` 都命中固定尺寸 CSS：正文内部滚动、面板 `height:100%`，因此较短模型面板无法收紧，较长面板可能被折叠。
- 智能画布通用缩放会同时写入 `node.w/node.h`，没有视频节点专用宽度上限。
- LinkFox、H3 和可灵 CLI 的参数结构高度明显不同，切换均通过节点重绘完成。

## 技术方案

1. 将普通视频和影视视频归入明确的视频自适应布局策略：宽度有上下限，高度只由当前 DOM 内容决定。
2. `film-video` 提示词保持稳定编辑器高度，长内容在 textarea 内滚动；不再调用会写入节点高度的通用文本自适应。
3. 智能画布渲染 `film-video` 时忽略历史高度并输出自动高度类；渲染后测量真实高度，用于连线和小地图几何同步，但不把测量值重新作为 CSS 固定高度。
4. 自动高度视频节点的缩放手柄只允许横向调整，并限制在设计宽度区间；纵向拖动不改变布局。
5. CSS 解除自动高度影视节点的 `height:100%` 和内部滚动，让工具栏、输入端口状态、资产映射、提示词、模型参数和动作区按自然文档流完整展开。
6. Playwright 依次执行可灵 CLI → H3 → LinkFox → 可灵 CLI 往返切换，测量节点边界、内容高度、滚动宽度、操作按钮、缩略图/映射区可见性及留白变化。

## 验收标准

1. 两类视频节点在可灵 CLI、H3、LinkFox 间任意切换后，外框高度与当前完整内容一致，不保留上一面板产生的大片空白。
2. 从短面板切到长面板时，所有参数、缩略图/资产映射、提示词和动作按钮完整可见且可点击，无折叠、裁切或相互遮挡。
3. 从长面板切回短面板时节点立即收紧，节点 body 不出现用于补齐旧高度的空白区。
4. 普通视频缩略图区维持六列正方形网格，第七个起换行，任何模型切换后均不可收缩。
5. 影视视频的资产映射和输入状态区不可被参数区挤压；底部“解析动作”和“生成视频”按钮始终位于外框内。
6. 视频节点只能在规定宽度范围内横向调整，纵向拖动不制造固定高度或布局混乱。
7. 节点尺寸变化后连线端点和小地图几何同步更新。
8. 相关 JS 语法、Python 定向测试和隔离 Playwright 几何/截图回归通过。
