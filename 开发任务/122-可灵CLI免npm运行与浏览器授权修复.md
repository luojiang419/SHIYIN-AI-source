## 任务目标

Windows x64 安装用户不必安装 Node.js、npm 或全局可灵 CLI，即可选择账号区域并在浏览器完成官方授权、读取模型和使用现有生成链路。

## 技术方案

- 锁定官方 CLI 中国/海外 0.1.3 包与 Node 22.23.2 Windows x64 校验值；直接解包，不执行 npm 或安装脚本。
- 安装包构建阶段准备 app/runtime/kling 组件；运行时优先读取已选择区域的内置或 data/system/components/kling-cli 组件，兼容已有全局 CLI。源码运行缺失组件时自动下载并验证，持久化区域。
- 区域包独立存放，首次由用户在节点选择；不修改系统 PATH、全局 npm 或已有凭据位置。
- 官方 login 子进程隐藏控制台、捕获授权 URL、记录进行中/成功/失败；限定本机管理员访问授权管理接口；重复点击复用正在进行的授权。
- 前端准备组件后继续登录，轮询授权结果并刷新动态模型；可手动打开授权链接，不再仅凭 PID 宣称浏览器成功打开。

## 验收标准

- 空 PATH / 无 npm 的 Windows 环境能执行官方 CLI --version，已授权用户仍走原生成服务。
- 安装包 staging 包含 Node 与中国/海外 CLI；不依赖构建机全局 kling。
- 未授权时有区域选择和连接入口；失败提示可见、链接可用、授权成功后自动刷新。
- 校验失败不激活组件；重复请求不重复下载或开启多个 OAuth 回调。
- 远程普通账号保持原有能力读取/生成权限，不得触发主机授权或读取授权 URL。
