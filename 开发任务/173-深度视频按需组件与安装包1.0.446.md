## 验收标准

1. 安装包不包含 VDA 模型权重、GemDepth 权重或技术验证输出。
2. 安装包包含无需系统 Python 的深度视频 worker、固定 revision 的 VDA 源码以及 FFmpeg/FFprobe。
3. 首次运行深度视频节点时自动下载 VDA Base 权重，支持断点续传、大小/SHA-256 校验、失败重试和原子切换。
4. 与人物深度组件共用软件设置中的局域网源和服务器端口；局域网源优先，失败后再走国内镜像和官方源。
5. 已安装模型可通过同一局域网服务器生成清单并支持 Range 分发。
6. 模型未安装或下载中时节点显示真实状态与进度；完成后自动继续生成。
7. 1.0.446 安装包构建成功，包内门禁、冻结后端烟雾、PE 版本、大小和 SHA-256 均通过。
