## 目标

- 主安装包不再携带 PyTorch/CUDA 深度视频运行时。
- 人物深度与深度视频运行时支持按 Windows 架构、GPU 类型、显存和 CUDA 能力选择制品。
- NVIDIA 档位启动或 smoke 验证失败时自动回退 CPU 档位，避免客户机因构建机环境不同而永久不可用。
- 模型继续使用现有 `person-depth` 与 `video-depth` 固定资源，不随软件热更新重打包。
- 分发中心新增独立运行时资源，支持清单、逐文件哈希和断点下载。

## 已交付

- 从全量安装构建移除约 4.02 GiB 解包体积的深度视频运行时；模型仍保持独立固定资源。
- schema v2 按 Windows 架构、GPU 类型、compute capability、显存和驱动版本选择运行时。
- RTX 50（`sm_120`）选择 PyTorch 2.7.1 + CUDA 12.8；RTX 20/30/40 选择 PyTorch 2.6 + CUDA 12.6；无兼容 CUDA 时回退 CPU。
- 选中档位 smoke 失败会继续尝试下一兼容档，并持久化成功档位。
- 运行时清单使用分发中心 Ed25519 签名，客户端在下载可执行 ZIP 前验证固定公钥。
- 分发中心已部署新资源类型，`video-depth-runtime` 1.0.0 已发布；热更新 `20260916125636` 已发布，最低桌面基线 1.0.447。
