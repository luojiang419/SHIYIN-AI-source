## 目标与实现

非局域网客户端仍可通过原有公网源补齐人物深度组件和深度视频模型；深度视频运行时原先只有局域网来源。新增可从本机目录导入运行时 ZIP 的入口。客户端清单固定 CUDA 12.8、CUDA 12.6、CPU 三档文件大小与 SHA-256，只接受适配本机的已知制品，安装后执行现有 smoke 验证。局域网自动下载保持优先，模型固定资源不重新发布。

运行时制品位于 `dist/video-depth-runtime/`。用户取得文件后，点深度视频节点的“导入运行时”，填写 ZIP 所在文件夹路径。节点会在导入成功后重试生成。全量安装包仍不包含这些大体积运行时。

本机产物：`dist/installer/SHIYIN-AI-Setup-2.0.0.exe`，115523183 字节，SHA-256 `C6F1283B1FCF280D4DB0C31A7AFD3FCC1394ED396196E7889F8CFE24C759056A`。staging 清单包含三档固定哈希，网页脚本包含导入入口。安装包未在用户正式客户端上覆盖安装。

## 验收

- 无局域网来源时，本地导入成功后运行时处于 ready，视频任务可继续。
- 篡改或不匹配的运行时 ZIP 被拒绝，不执行。
- 全量安装包包含新 API、节点入口和固定运行时清单；不包含运行时 ZIP。

## 公网自动补齐续作

用户明确要求非局域网时自动下载，而非默认弹出手动路径。`PersonDepthComponentManager._download_and_install()` 按局域网、国内源、镜像、官方源顺序回退。最终 CUDA 字节块制品与 SHA-256 清单在 `dist/video-depth-runtime-chunks/`；CPU 保留已发布的独立 ZIP。新增测试验证局域网不可达时自动下载字节块、重组和安装，以及 CUDA 自检失败后转 CPU。

ModelScope 公开仓库为 `jiangjiang419/shiyin-video-depth-runtime`，21 个资源已完成匿名 Range 和远端哈希/大小验收。英伟达/PyTorch 官方只提供基础依赖，不提供本应用冻结后的 worker。离线导入继续作为网络不可用时的兜底。

深度视频模型的内置国内源已调整为 ModelScope，`hf-mirror.com` 和 Hugging Face 为依次回退；运行时本地导入兼容上一版单 ZIP。GitHub 备用 Release 草稿 `video-depth-runtime-v1.0.0` 只上传了 CPU 分片，草稿没有公开，不用于客户端。ModelScope 大文件单次 PUT 断连后，CUDA 改为原 ZIP 字节块：CUDA 12.8 共 11 块，CUDA 12.6 共 9 块；每块固定 SHA-256，客户端下载后重组并验证原始 ZIP SHA-256，之后才解压和 smoke。公网 CUDA 失败时继续尝试 CPU 档。

2026-09-17 最终重编安装包：`dist/installer/SHIYIN-AI-Setup-2.0.0.exe`，115523210 字节，SHA-256 `D6FB2E613E609EDB1C90884C94E2A769BF7F5A07E71BFE8BE16ED7770193B7FB`。staging 已包含 21 个视频运行时资源项、13 个人物深度国内块与 ModelScope URL。桌面 smoke 因用户正式实例运行而跳过；打包后端在系统临时目录通过隔离健康/状态/API 权限检查。第一次在 `.build` 临时目录启动曾遇 `backend.json` 原子替换 WinError 5，系统临时目录复测未复现；独立画布像素烟测此前失败，不标记为通过。
