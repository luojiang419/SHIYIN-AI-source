## 验收与兼容

- 取消内置管理员账号密码，通过注册设置账号，首个本机注册账号为管理员；并发注册不能产生多个管理员，远端不能抢占首次管理员。
- 管理员仍使用既有 `admin` 数据作用域，保留旧版画布、素材与配置；旧普通账号保持原角色及数据目录。旧硬编码管理员会话失效，需首次设置新账号。
- API 配置等敏感接口继续由后端按角色校验，普通账号不能访问。
- 首次账号设置作为已有 API 引导的前置步骤，说明只需首次注册、桌面后续自动登录以及多人数据隔离；注册后直接进入。
- 桌面本机登录令牌使用现有安全存储加密持久化，重启及 Cookie 丢失时恢复；主动退出、改密或禁用后不能恢复旧会话。
- Web 会话仍保留期限，不从桌面保存的凭据恢复。
