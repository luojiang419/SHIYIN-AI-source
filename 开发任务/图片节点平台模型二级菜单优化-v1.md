## 任务目标

将图片节点下面的平台和模型原生下拉框改为可悬停展开的二级菜单，减少窄面板中的文字挤压，并保持平台、模型、画幅、分辨率和生成操作在同一行或稳定响应式布局中。

## 技术方案

- 使用 `.image-quick-choice` 包装触发按钮、隐藏值输入和菜单面板。
- 平台/模型选项使用按钮渲染，保留当前值高亮和 `check` 图标。
- 通过 CSS `:hover`、`:focus-within` 与 JS `pointerenter/pointerleave` 控制展开折叠；离开使用短延迟避免跨越面板间隙时闪烁。
- 平台切换沿用 `resolveImageProviderId()` 和 `allImageModels()`，自动选中新平台的第一个模型并刷新模型菜单。

## 验收标准

- 平台和模型控件不再依赖原生下拉框的窄宽度展示。
- 鼠标移入触发按钮或菜单时自动展开，移出后自动折叠。
- 平台切换后模型列表和节点 `model` 字段立即同步。
- 长平台名、模型名不会撑破图片节点面板。
- 相关 JavaScript 静态检查和测试通过。
