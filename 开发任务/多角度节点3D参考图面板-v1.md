## 技术方案

- 本地静态资源位于 `static/assets/camera-reference/`，附带来源和许可证说明。
- 角度节点按 `yaw`（左负右正）和 `elevation` 分桶，切换预览图并同步 `angleDirectorCaptureUrl`。
- `generateClassicSpecialEdit` 和 `generateSmartSpecialEdit` 只在 `angleGeometryMode === "director3d"` 时把静态参考图放在原图之后作为 Image 2。
- 深度模型接口和历史 `angleDepth*` 字段暂不删除，旧数据统一落到 3D 参考模式，避免破坏已有画布。

## 验收标准

1. 角度节点面板右侧始终显示当前区间对应的 3D 参考图和 Image 2 标识。
2. 拖动水平/俯仰控件或点击预设时，参考图和区间标签同步变化。
3. 角度生成请求顺序为主体原图 → 静态 3D 参考图 → 上一轮结果。
4. 深度图按钮和深度模式不再出现在角度节点 UI，旧画布不会报错。
5. 相关 JS 语法、契约测试和 diff 检查通过。
