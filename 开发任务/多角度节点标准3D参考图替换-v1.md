## 任务目标

将多角度节点的抽象骨架参考替换为统一材质、统一姿势、统一比例的完整 3D 人偶参考图；俯仰滑块覆盖 `-45°～60°`，右侧参考图和 API 的 `Image 2` 使用相同的角度区间素材。

## 角度区间设计

- `-45°～-16°`：仰拍低机位，代表角度 `-45°`。
- `-15°～15°`：平视，按水平角映射正面、斜前、侧面和背面。
- `16°～45°`：俯视机位，代表角度约 `+30°`。
- `46°～60°`：高俯视机位，代表角度约 `+55°`。

## 技术方案

- 新增统一命名的静态参考图片，所有图片使用完整、穿不透明连体服的中性 3D 人偶，禁止骨骼、线框、动作姿态和局部截图。
- 扩展 `normalizeAngle()`、范围输入、拖拽轨道和机位标记的俯仰下限为 `-45`。
- `angleReferenceCard()` 先按俯仰区间选择仰拍/俯视/高俯视素材；平视区间再按水平角选择正面、斜前、侧面或背面素材。
- `syncDirectorReference()` 将同一个 `angleReferenceCard()` 的静态素材写入节点；经典和智能 API 生成函数从节点读取该素材并加入 `reference_images`，保证右侧预览与提交内容一致。
- 保留已连接的 3D 导演台动态截图优先能力；没有动态截图时使用当前静态标准参考图。
- 后端将 `/static/assets/` 纳入内部媒体路径白名单和本地文件映射，让 OpenAI multipart、Gemini、ModelScope、即梦、GrsAI、火山和 RunningHub 等供应商收到真实图片内容。
