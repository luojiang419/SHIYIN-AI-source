## 任务目标

让自动解析和提示词润色结果始终符合对应视频模型的提示词字符上限；MiniMax H3 使用 7000，Kling 使用 2500；取消统一 4000 字符拦截，避免 H3 被错误弹窗拦截。

## 技术方案

- `CanvasVideoRequest` 只保留较宽的内部传输上限，避免在 Pydantic 层产生固定 4000 错误。
- 新增 `video_prompt_limit(provider_id, model)` 统一解析模型上限。
- 自动解析/润色系统提示词声明硬性字符上限；结果超限时调用同一文本模型压缩，仍超限时按句子边界兜底截断。
- `/api/canvas-video` 与 `/api/canvas-video-tasks` 提交前执行模型级校验，错误消息显示真实模型上限。

## 验收标准

1. MiniMax H3 的 4000～7000 字符提示词不再触发 4000 字符后端校验。
2. Kling 超过 2500 字符时不再显示 4000，而显示对应模型限长。
3. 自动解析和润色返回结果 `len(text) <= video_prompt_limit(...)`。
4. H3/Kling 引用标签、既有自动解析测试和普通视频生成流程不回归。

## 已完成内容

- 统一画布视频请求体上限提升为内部安全上限 20000，不再固定为 4000。
- MiniMax H3 默认 7000 字符、Kling 默认 2500 字符，并支持环境变量覆盖。
- 自动解析和润色系统提示词注入模型级长度硬约束；超限结果自动调用压缩模型，仍超限时按句子边界兜底。
- `/api/canvas-video` 与 `/api/canvas-video-tasks` 提交前统一校验，错误提示显示真实模型上限。
- H3/Kling skill 文档补充限长规则，回归测试覆盖动态限长、自动压缩和模型级错误。
