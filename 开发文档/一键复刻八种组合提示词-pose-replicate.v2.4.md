# 一键复刻八种组合提示词（pose-replicate.v2.4）

导出日期：2026-09-05

来源：`canvas_core/pose_replicate_prompts.py` 中的 `pose_replicate_template_catalog()`。本文档由当前运行时编译器直接展开，记录“一键复刻”节点在没有用户补充要求、没有自定义模板时使用的八种默认提示词。

## 使用与优化说明

- 八种组合由“深度 / 骨架 × 无 / 有模特主体 × 无 / 有场景”排列得到。
- `{{output_aspect_ratio}}` 是运行时画幅占位符，生成时会替换为 `1:1`、`16:9`、`9:16`、`4:3` 或 `3:4`。
- 下文每组的“参考图顺序”就是实际提交顺序；优化提示词时不要交换图号或改变角色所有权。
- 在节点设置中保存的自定义模板会完整替换对应组合的默认模板。自定义模板可使用 `{{output_aspect_ratio}}` 和 `{{user_instruction}}`；如果未写 `{{user_instruction}}`，节点内的补充要求会追加到模板末尾。
- 修改本文档不会自动修改程序运行时模板。确认优化稿后，应同步修改编译器或复制到节点的对应组合设置中。
