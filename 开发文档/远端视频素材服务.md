# 远端视频素材服务

## 目的

可灵 Omni 的 `--video` 参考视频要求公网 HTTP(S) 地址。本项目的截取片段仍保存在本机画布目录，生成前通过 SSH/SCP 上传到香港服务器，再由独立的只读媒体服务提供公网地址。

## 端口边界

- 远端媒体服务只监听 `0.0.0.0:18080`。
- 现有 `80/443/8080/3413/3212/3213` 和 OpenResty 配置不参与本功能，也不会被部署脚本改写。
- 部署脚本发现 `18080` 已占用时会直接中止。

公网地址格式：

```text
http://64.90.17.178:18080/clip/<account>/<canvas>/<clip>.mp4
```

## 上传和删除

- 上传：本地后端使用 SSH/SCP 密钥上传到 `/opt/clipdata/<account>/<canvas>/<clip>.mp4`。
- 删除节点：本地视频片段删除 API 同步通过 SSH 删除同一路径的远端文件。
- 删除画布：画布 purge 同步删除远端画布目录。
- 公网服务只读，不开放上传、删除 HTTP API。

## 自动清理

远端 `clip-media-gc.timer` 每 15 分钟执行一次：

- 目录总量不超过 10 GiB 时不删除。
- 超过 10 GiB 时从最旧文件开始清理，目标降到约 9.2 GiB。
- 文件未满 1 小时不会被 GC 删除，避免刚上传或正在被可灵读取的片段被清理。
- 节点删除仍然是首选的即时回收路径，10 GiB 规则是异常退出、刷新或遗留文件的兜底。

## 本机配置

源码运行时会自动寻找：

```text
api文档/香港云key/id_ed25519_1panel
```

也可以通过环境变量覆盖：

```text
CLIP_REMOTE_MEDIA_ENABLED=1
CLIP_REMOTE_SSH_HOST=64.90.17.178
CLIP_REMOTE_SSH_PORT=419
CLIP_REMOTE_SSH_USER=root
CLIP_REMOTE_SSH_KEY_PATH=<本机私钥绝对路径>
CLIP_REMOTE_ROOT=/opt/clipdata
CLIP_REMOTE_PUBLIC_BASE_URL=http://64.90.17.178:18080/clip
```

私钥不会复制进安装包、不会写入 Git，也不会写入日志。安装包环境应通过 `CLIP_REMOTE_SSH_KEY_PATH` 指向本机受 ACL 保护的私钥。

## 部署

```powershell
powershell -ExecutionPolicy Bypass -File tools/deploy-remote-clip-service.ps1 `
  -KeyPath "<私钥绝对路径>"
```

部署内容位于远端 `/opt/clipdata/.service`，systemd 单元为 `clip-media.service`、`clip-media-gc.service` 和 `clip-media-gc.timer`。
