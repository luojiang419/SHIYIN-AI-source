# 进度快照 579：分层浏览器缓存刷新策略

## 已完成内容

- 版本已从 `1.0.272` 递增到 `1.0.273`。
- 新增 `VersionedStaticFiles`：带 `v=` 的静态 JS/CSS 等资源使用 `public, max-age=31536000, immutable`；无版本静态资源保持重新校验。
- HTML 页面统一使用 `no-store, max-age=0, must-revalidate`：首页、登录页、管理员页和直接访问的 `/static/*.html` 页面均不会复用旧页面壳。
- Service Worker 以加载脚本的 `v=` 参数作为缓存版本，升级激活时会清理旧版本生成图缓存。
- 未带内容修订参数的生成图片与预览接口改为网络优先、离线时回退缓存；带 `rev`、`v`、`hash` 或 `version` 的内容版本化图片继续缓存优先。
- 新增 `ShiyinMediaCache.invalidate(urls)` 与 Worker 单项缓存失效消息。
- 新增 HTTP 缓存响应头回归测试；定向回归及全量测试通过。

## 当前修改模块

- `main.py`：HTML、Service Worker 和 `/static` 响应缓存头。
- `static/media-cache-sw.js`：缓存版本、网络优先策略与单项失效。
- `static/js/media-cache-client.js`：从自身版本 URL 派生 Worker 版本，并暴露失效调用。
- `tests/test_web_cache_policy.py`、`tests/test_generated_image_browser_cache.py`：缓存策略回归。

## 代码前后对比

```diff
- HTML: Cache-Control: no-cache
+ HTML: Cache-Control: no-store, max-age=0, must-revalidate

- /static/*: 由浏览器按默认策略处理
+ /static/*?v=<版本>: public, max-age=31536000, immutable
+ /static/* 无版本: no-cache, max-age=0, must-revalidate

- 生成图片: Service Worker 始终缓存优先
+ 无内容修订号的生成图片/预览: 网络优先，断网时回退缓存
+ 带 rev/v/hash/version 的图片: 缓存优先
```
