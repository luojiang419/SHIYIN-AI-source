## 具体代码前后对比

### 1. 普通视频节点切换到可灵 CLI

旧版：

```javascript
node.model = klingModelsForNode(node)[0]?.model || '';
```

新版：

```javascript
node.model = preferredKlingOmniModel(node);
```

旧逻辑选择能力列表第一个模型，当前官方列表第一个通常是只支持 5/10 秒的 2.5；新逻辑默认进入支持 3–15 秒的 3.0 Omni。

### 2. 时长选项来源

旧版行为：所有可灵模型的 `duration` 都在前端无条件补齐 3–15，后端仍按模型原始能力校验。

新版行为：前端只渲染后端返回的当前模型 `allowed_values`；后端仅把 `kling-video-v3_0*` 的 `duration` 归一化为 3–15，2.5/2.6/O1 继续保留当前模式的真实能力。

### 3. 旧节点无效状态

旧版行为：下拉框视觉上可能回到首项，但 `modelParameters` 仍保存并提交旧的 6 秒。

新版行为：保存值不在 `allowed_values` 时回退到模型默认值或首项，并同步 `node.duration`、`aspectRatio`、`resolution`、`generateAudio` 与 `modelParameters`。
