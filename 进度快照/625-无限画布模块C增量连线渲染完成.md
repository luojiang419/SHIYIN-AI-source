## 已完成内容

- 经典画布新增 `CLASSIC_INCREMENTAL_LINKS` 开关、`classicConnectionDirtyIds` 和结构脏标记。
- 经典节点拖动/尺寸变化只反查并更新相邻连接的 path、hit path 和删除按钮；连接新增、删除、刀切、索引缺失时保留 `renderLinks()` 全量回退。

- 智能端口临时线继续使用独立 `port-drag-temp` path；连接层全量替换时保留临时 path 的当前几何。
- 新增 `tests/test_canvas_incremental_connections.py`，覆盖开关、脏连接、DOM 索引、全量回退和临时连线隔离契约。

拖动/缩放先调用 `markClassicConnectionsDirtyForNodes(...)`；`renderClassicTempLink()` 单独处理临时 path。普通滚轮缩放只应用 world transform。

## 已解决踩坑点

- 智能连接 SVG 的 `data-conn-index` 可能是合并后的逗号列表，因此增量路径仅接受单连接普通项；遇到分组/历史/合并项必须全量回退。
- 临时端口线不能放入 connectionId 索引，否则全量连接刷新会误删拖动反馈；现保留独立 `port-drag-temp`，替换 SVG 时转移当前 `d` 属性。
- 经典画布滚轮缩放只改变 world transform，节点和连线同属 world，不需要重复读取端口矩形；临时连线存在时才单独刷新。
- 全量 `python -m unittest discover -s tests` 会受外部 API Key 和既有字符串契约影响，模块验收以专项测试、语法检查和 diff 检查为准，并在主文档记录环境异常。
