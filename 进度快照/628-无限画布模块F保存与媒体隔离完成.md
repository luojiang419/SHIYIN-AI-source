# 进度快照 628：无限画布模块 F 保存与媒体隔离完成

日期：2026-08-24

## 已完成内容

- 经典画布增加 `CLASSIC_SAVE_QUEUE_ENABLED` 和 `localCanvasSaveSequence` 响应保护。保存请求期间若本地序列继续前进，旧响应只吸收服务端 `revision/updated_at`，不覆盖当前节点、连线和视口编辑。
- 智能画布增加 `SMART_SAVE_QUEUE_ENABLED` 和 `smartLocalSaveSequence`，在原有 `canvasSyncInFlight` 单飞队列上识别更新中的本地编辑，并单调更新服务端 revision/时间戳。
- 经典/智能画布自然尺寸测量拆分为 `measure*Now()` 实际函数和空闲调度包装器，按根节点合并请求，优先 `requestIdleCallback`，不支持时使用 `setTimeout`。
- 经典/智能整场景图标刷新移到空闲阶段；智能增量节点仍保留局部 `refreshIcons(root)`，不延迟新节点必要反馈。
- 新增 `CLASSIC_IDLE_MEDIA_ENABLED`、`SMART_IDLE_MEDIA_ENABLED` 开关，异常时可恢复同步测量/图标路径。
- 新增 `tests/test_canvas_save_media_isolation.py`。

## 具体代码前后对比

### 经典画布 `static/js/canvas.js`

修改前：已有 `savingCanvasNow/saveCanvasAgain`，但保存成功后直接将 `data.canvas` 整体合并到当前 `canvas`；如果请求期间本地编辑继续发生，旧响应可能携带旧节点/连线快照。

修改后：保存开始记录 `savingSequence`；成功响应判断 `saveHadNewerEdits`。无更新时只在保留当前节点/连线/视口引用的前提下合并元数据；有更新时只单调吸收服务端 revision/时间戳，并保持本地编辑。

修改前：`render()` 同步执行整棵节点树的原图尺寸测量和 Lucide 图标扫描。

修改后：自然尺寸测量和整场景图标刷新进入空闲队列，重复调用按根节点合并；局部增量节点与媒体播放恢复路径保持不变。

### 智能画布 `static/js/smart-canvas.js`

修改前：已有单飞保存，但没有本地保存序列判断；成功响应直接写入服务端时间戳和 revision。

修改后：`scheduleSave()` 递增 `smartLocalSaveSequence`，保存请求记录序列和基线 revision；响应只单调更新元数据，并识别是否有更新的本地编辑。

修改前：`render()` 同步调用 `refreshIcons(world)` 和 `measureSmartNodeImages(...)`。

修改后：整场景图标改为 `scheduleSmartIdleIconRefresh(world)`；图像测量改为 `measureSmartNodeImagesNow()` + 空闲包装器，局部 mutation 继续即时刷新图标。

## 已解决踩坑点

- 保存响应不能直接整体覆盖当前 `canvas`，否则会把请求期间的新编辑回滚；已通过本地保存序列和保留当前节点/连线引用解决。
- 空闲回调中的根节点可能已经被替换；执行前检查 `isConnected`，断开时回退到当前画布根节点。
- 多次 render 可能重复排队媒体测量或图标刷新；已使用 Set 合并根节点和单个 idle handle。
- 旧浏览器不支持 `requestIdleCallback`；已统一回退到 `setTimeout`。
- 高风险保存/空闲隔离保留四个显式开关，出现异常时可恢复原路径。
