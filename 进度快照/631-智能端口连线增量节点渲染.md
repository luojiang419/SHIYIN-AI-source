## 已解决踩坑点

- 静态脚本固定 query 可能被浏览器缓存；需清理浏览器缓存后重新加载 iframe，才能验证新 JS。强制刷新顶层页面可能弹出 API Key 提示，只点击“稍后设置”。
- 端口连线 mutation 只能替换目标节点；连接 SVG 结构仍需刷新，不能直接跳过连接层更新，否则命中区域和删除/刀切事件会失效。
- 真实鼠标复核必须使用 CDP `Input.dispatchMouseEvent`，合成 DOM MouseEvent 无法证明浏览器输入路径完整。
