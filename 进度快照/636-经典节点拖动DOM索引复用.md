# 636-经典节点拖动 DOM 索引复用

## 已完成内容

- 从快照 635 继续，确认经典 `onNodeDrag()` 每个拖动事件都会通过 `nodesEl.querySelector()` 查找主节点和组/多选子节点 DOM。
- 在 `static/js/canvas.js` 增加 `CLASSIC_DRAG_DOM_INDEX_ENABLED` 开关。
- `startNodeDrag()` 记录主节点与子节点的 `canvasNodeDomIndex` DOM 引用；`onNodeDrag()` 优先复用引用和索引，索引缺失或开关关闭时回退原选择器查询。
- 未改变拖动位置计算、分组/多选移动、几何缓存失效、连接层增量刷新、小地图脏区调度、撤销重做或保存语义。

## 当前模块

统一验收后的经典节点拖动低风险 DOM 查询优化。范围仅限拖动帧节点位置写入，不扩大到智能拖动或平移路径。


## 已解决踩坑点

- 拖动开始时记录 DOM 引用必须保留索引缺失回退；Alt 拖动会先触发全量 render，不能假设旧引用仍连接到文档。
- 只替换主节点查询会遗漏组/多选子节点；子节点引用必须和其原始位置快照一起存入 `dragNode.children`。
- 拖动 DOM 查询优化不能移除 `invalidateCanvasGeometry`、连接脏区标记或小地图更新，这些仍是功能正确性所需路径。
