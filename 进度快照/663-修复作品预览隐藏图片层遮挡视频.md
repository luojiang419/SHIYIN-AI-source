# 修复作品预览隐藏图片层遮挡视频

## 根因

作品预览框同时保留 `img#worksPreviewImage` 和 `video#worksPreviewVideo`。切换视频时 JS 设置了 `image.hidden = true`，但 `image-preview.js` 对 `.studio-preview-img` 设置了作者样式 `display:block`，覆盖浏览器对 `[hidden]` 的默认隐藏规则。于是旧图片层覆盖视频；由于图片层 `pointer-events:none`，点击下方才会穿透到视频，造成“视频不能点、点下方才全屏”的假象。

## 修改

- `static/css/works.css` 新增 `.works-preview-frame > [hidden] { display:none !important; }`，保证切换到视频时图片层从布局和绘制树中移除。
- 版本从 1.0.294 递增到 1.0.295，更新所有版本源与发布说明，强制 WebView 重载 CSS。
