# 修复打开目录落到文档目录

## 已完成

- 定位到作品接口返回的真实路径是正确的，例如 `D:\Program Files\SHIYIN AI\data\media\generated\kling_8ddc4f9104.mp4`。
- 定位到 Windows Explorer 调用参数问题：`subprocess.Popen([explorer, '/select,"带空格路径"'])` 会经过 Python/CreateProcess 二次转义，Explorer 解析失败后静默打开默认“文档”目录。
- 改为传入完整命令行字符串：`"explorer.exe" /select,"C:\\path\\file"`，保留文件选择功能并正确处理空格。
- 路径解析仍然只允许真实存在的本地文件；远程 URL 或不存在路径不会猜测同名文件，也不会打开默认目录。
- 版本号递增至 `1.0.301`。
