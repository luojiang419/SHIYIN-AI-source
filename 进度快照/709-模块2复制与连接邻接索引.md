# 进度快照 709：模块 2 复制与连接邻接索引

## 已完成内容

- 经典复制使用 `canvasNodeIndex`，智能复制使用 `smartNodeIndex`，不再对每个选中 ID 调用 `nodes.find(...)`。
- 经典复制复用连接模型索引；智能复制维护 `nodeId -> connection indexes` 邻接索引。
- 两套复制只合并选中节点的相邻连接，再保留端点都在复制集合中的内部连接。
- 复制组节点时递归收集成员并去重；智能粘贴把 `copy.items` 重映射为新成员 ID。

## 已知风险与恢复说明

- 连接索引计数不一致时会单次全量重建；正常复制路径不会扫描全连接。
- 智能连接多数没有持久化 ID，因此邻接索引使用当前连接数组序号；每次连接层重建都会同步刷新。
- 恢复开发时第一步必须完整读取 `E:\APP\SHIYIN-AI\开发文档\无限画布菜单与剪贴板性能优化方案-v2.md`。
