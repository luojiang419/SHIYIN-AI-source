## 具体代码前后对比

```text
改动前：addNode -> nodes.push -> render；mutation -> new Map(all nodes) -> rebuildCanvasDomIndexes(all DOM)。
改动后：addNode -> canvasNodeIndex.set -> queue createdIds；mutation -> index/remove target node DOM only。

改动前：invalidateCanvasGeometry([id]) 也递增全局 epoch，所有端口缓存随之失效。
改动后：指定 ID 只删除该节点矩形和端口几何；仅全量失效递增 epoch。

异常前：单节点渲染失败只输出 error 并继续，可能留下索引不一致。
异常后：console.warn 记录 node-dom-index-patch 原因并执行完整 render。
```
