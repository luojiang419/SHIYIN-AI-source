## 具体代码前后对比

```text
改动前：各菜单构造函数直接 nodes.push(node) -> render() -> scheduleSave()，创建路径不统一且多数触发完整渲染。
改动后：commitSmartNodeCreate(node, options) -> smartNodeIndex.set -> queueSmartRenderMutation(createdIds) -> render() -> scheduleSave()。

改动前：三视图/批量处理先创建节点再完整 render，来源连接不能稳定并入创建差异。
改动后：deferRender/deferSave -> connectInputNode() 记录连接差异 -> 单次创建 mutation 提交。

改动前：分组菜单整理后直接 render，局部节点替换和模型索引变化不明确。
改动后：维护 group/member 索引并提交 removeIds/replaceIds mutation。
```
