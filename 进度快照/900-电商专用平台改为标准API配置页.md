## 代码前后对比

### 后端模型字段

- 修改前：`ecommerce-vision` 的 `image_models`、`video_models` 在规范化时被清空，协议被强制为 `openai`。
- 修改后：仅 `local-vision` 保持视觉专用限制；电商平台按普通平台保留用户输入的三类模型和协议。

### 前端页面判定

- 修改前：`isVisionProviderId` 同时包含 `local-vision` 与 `ecommerce-vision`，导致 CSS 隐藏图片/视频区块，页面只剩视觉模型。
- 修改后：该判定只包含 `local-vision`；电商平台使用标准模型列表和协议选择界面，同时保留内置平台 ID。
