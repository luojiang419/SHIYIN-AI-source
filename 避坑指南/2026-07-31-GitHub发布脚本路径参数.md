# GitHub 发布脚本路径参数

## 问题

调用 `tools/publish-release.ps1` 时，如果把 `-AssetPath`、`-ChecksumPath` 或 `-ReleaseNotesPath` 传入 `Resolve-Path` 得到的绝对路径，脚本内部会再次与项目根目录拼接，最终形成重复路径并失败。

## 解决

从项目根目录调用发布脚本时，这三个参数使用项目内相对路径，例如 `dist/installer/SHIYIN-AI-Setup-1.0.104.exe`、对应的 `.sha256` 和 `release-notes/current.md`。脚本会自行解析为绝对路径。

## 后续约定

发布前先确认脚本参数的路径语义；只有脚本明确接受绝对路径时才传入 `Resolve-Path` 结果。
