# GitHub `.sha256` 下载内容需显式 UTF-8 解码

## 现象

使用 PowerShell 的 `Invoke-WebRequest` 下载 GitHub Release 中的 `.sha256` 文件时，部分运行环境会把 `response.Content` 返回为 `byte[]`，直接调用 `.Trim()` 会报错：`System.Byte does not contain a method named 'Trim'`。

## 原因

`Invoke-WebRequest` 的 `Content` 返回类型会随 PowerShell 版本、响应头和处理路径变化；不能假定其始终是字符串。

## 正确做法

先按返回类型处理，再比较校验文本：

```powershell
$raw = $response.Content
$remote = if ($raw -is [byte[]]) {
    [Text.Encoding]::UTF8.GetString($raw).Trim()
} else {
    ([string]$raw).Trim()
}
```

这样才能可靠地与本地 `.sha256` 文件内容进行逐字比较。
