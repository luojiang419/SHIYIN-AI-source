# Windows 安装包冒烟前必须关闭运行中的 SHIYIN AI

## 现象

`tools/build-installer.ps1` 在桌面宿主编译完成后进入安装态冒烟时会失败，并提示：

```text
Desktop smoke test requires all existing SHIYIN AI instances to be closed first
```

## 原因

冒烟脚本需要独占启动、验证和关闭新的桌面实例。已运行的正式安装版会与测试实例共用单实例机制、端口或用户数据，导致测试结果不可靠，因此脚本主动拒绝继续。

## 处理方式

1. 先用 `Get-CimInstance Win32_Process` 核对 PID、可执行路径和启动时间；不能仅按进程名盲目终止。
2. 如果进程是用户正在使用的正式客户端，必须获得用户确认后才关闭。
3. 仅在确认目标为构建残留或用户允许时，终止该精确 PID，再重跑安装包构建。
