# 无限画布模块 C 增量连线回退边界

## 问题

智能画布连接层存在分组连线合并、history 连线和级联状态；这些 DOM 项可能对应多个连接 ID，不能简单用单个 connectionId 反查并 patch。临时端口连线也不属于持久化连接集合。

## 处理

- 只有普通单连接项写入 `data-connection-id` 并进入增量 DOM 索引。
- 分组、history、合并项、拓扑变化或索引数量不匹配时返回失败，立即回退既有完整 `refreshConnectionLayer()`。
- 临时端口线使用独立 `port-drag-temp` path，连接层替换时转移当前 `d` 属性，避免反馈线闪断。
- 经典画布同样用结构脏标记回退 `renderLinks()`，不以删除连线或关闭端口反馈换取性能。

## 验证

专项静态契约测试覆盖上述开关、回退和临时 path 隔离；两套画布 JS 语法检查通过。
