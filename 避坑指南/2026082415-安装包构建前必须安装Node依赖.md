# 安装包构建前必须安装 Node 依赖

## 现象

执行 `tools/build-installer.ps1` 时，PyInstaller 后端可以完成，但 Tauri 的 `npm run css:build` 报错 `Cannot find module node_modules/tailwindcss/lib/cli.js`，安装包不会继续生成。

## 原因

当前工作树未安装 `node_modules`，而构建脚本直接调用锁定的 Tailwind CLI 路径。

## 解决

在仓库根目录执行 `npm ci`，按 `package-lock.json` 恢复依赖，再重新运行构建脚本；本次重跑使用已成功生成的同版本后端产物并通过 Tauri、运行时冒烟与 Inno Setup。

## 后续规避

构建前先检查 `node_modules/tailwindcss/lib/cli.js` 和 `node_modules/@tauri-apps/cli` 是否存在；缺失时先执行 `npm ci`，不要修改锁文件或临时改写构建脚本。
