# 双画布功能入口必须分别接入并做真实 UI 验收

## 问题现象

智能画布已经具备“创建三视图”，但普通无限画布选中图片节点后，悬浮操作栏仍没有该入口。

## 根因

项目中的普通画布与智能画布不是同一套前端实现：

- 普通画布：`static/canvas.html` + `static/js/canvas.js`
- 智能画布：`static/smart-canvas.html` + `static/js/smart-canvas.js`

只修改其中一套，不会自动同步到另一套。

## 后续规避规则

1. 需求写到“图片节点”“无限画布”时，先确认截图或实际路由属于哪套画布。
2. 若需求要求两套画布一致，分别检查新建菜单、图片悬浮菜单、节点渲染、输入端口、连线规则、生成执行与缓存键。
3. 自动化测试之外，必须在两套真实页面分别点击入口；至少核对菜单文字、节点数量、端口数量、自动连线角色和浏览器错误日志。
4. 缓存键随前端脚本变更同步递增，避免安装升级后浏览器继续使用旧脚本。

## 本次验证模板

- 选中普通画布图片节点。
- 确认快捷栏包含“创建三视图”。
- 点击后确认新增 1 个多视图节点。
- 确认左侧 9 个语义端口。
- 确认源图片连接到 `model-front`。
- 确认浏览器错误日志为空。
