# 本轮画布功能回归注意事项

## 1. 业务后端页面需要登录

本地后端启动后，直接请求工程页接口可能返回“请先登录或注册账号”。静态页面样式检查不应尝试绕过登录，也不应在浏览器中输入账号或业务数据。需要做纯界面检查时，使用隔离的静态预览服务，只验证 DOM、样式和交互挂载；涉及真实创建画布、保存位置或导入媒体时，再使用已登录的业务环境。

## 2. 姿势参考字符串需要区分节点类型和动作参考角色

移除独立“姿势参考/导演台”节点时，不能全局删除 `pose-reference` 字符串。普通/智能一键复刻节点仍使用 `pose-reference` 作为动作参考输入角色，电商流程也仍有动作参考语义。应删除节点构造、页面入口、主体渲染和绑定接口，保留一键复刻的输入端口与骨架输出链路。

## 3. 批量导入排版必须在真实尺寸上复核

仅使用导入时的初始偏移量会在图片/视频节点实际渲染尺寸变化后产生重叠。批量导入应先测量真实 DOM 尺寸计算列宽和行高，再创建分组，并调用分组排版器按真实尺寸二次布局，最后让分组边界跟随成员尺寸更新。

## 4. 全量契约测试可能包含既有基线失败

本轮全量测试为 878 项通过、5 项失败；失败集中在 Blender 下游媒体、桌面更新发布、电商页面旧契约和统一主题缓存契约，未命中本轮修改模块。验收时应同时记录全量结果和本轮相关回归结果，避免把既有契约失败误判为本轮画布改动引入。
